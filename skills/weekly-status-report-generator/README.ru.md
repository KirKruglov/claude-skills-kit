# Weekly Status Report Generator

Превращает сырые заметки недели в два готовых статус-отчёта — для менеджера и skip-level — за один проход.

---

## Обзор

Weekly Status Report Generator трансформирует неструктурированные заметки недели в два формата для разных аудиторий за один проход: развёрнутый Статус-отчёт для менеджера и краткий Апдейт из 3 пунктов для skip-level. Скилл извлекает выполненные задачи, текущую работу, блокеры и планы на следующую неделю из любого формата заметок — списки, свободный текст или скопированные Slack-сообщения. Используй этот скилл, когда нужно отправить отчёт по итогам недели, подготовить апдейт менеджеру или написать краткое резюме для skip-level без потери времени на форматирование.

---

## Требования

- Сырые заметки недели (любой формат: список, свободный текст, скопированные Slack-сообщения или их смесь)
- Дополнительные файлы, инструменты или интеграции не нужны

**Лучше работает с:** заметками, охватывающими 2–10 пунктов — выполненные задачи, текущая работа и планы. При очень коротких заметках (1–2 пункта) отчёты будут краткими; скилл предупредит об этом.

---

## Как использовать

1. **Собери заметки недели**
   - Что угодно за неделю: выполненные задачи, встречи, блокеры, планы на следующую неделю
   - Формат не важен — вставляй сырые списки, свободный текст или скопированное из Slack

2. **Активируй скилл**
   - Напиши: «Напиши мой еженедельный статус-отчёт» или «Преобразуй мои заметки в отчёт»
   - На английском: "Write my weekly status report" или "Turn my notes into a status report"

3. **Вставь заметки**
   - Скилл разберёт заметки и автоматически выделит структурированные пункты

4. **Получи два готовых отчёта**
   - **Статус-отчёт для менеджера:** разделы — Выполнено, В работе, Блокеры, На следующей неделе
   - **Краткий апдейт для skip-level:** 3 подписанных пункта — Топ-результат, Главная сложность, Фокус следующей недели
   - Скопируй каждый блок и вставляй напрямую в сообщение — редактирование не нужно

## Примеры

### Пример 1: Заметки в виде списка

**Входные данные:**
```
- Выкатил фичу поиска в прод (откатов нет)
- Сделал ревью 2 PR от бэкенд-команды
- Жду согласования юристов по партнёрской интеграции (заблокировано со вторника)
- Следующая неделя: запуск аналитической инструментации, 1:1 с тимлидом
```

**Результат:**
```markdown
## Статус-отчёт — Неделя 9 июня

### Выполнено
- Выкатил фичу поиска в прод (откатов нет)
- Сделал ревью 2 PR бэкенд-команды

### В работе
- Партнёрская интеграция — ожидаю согласования юристов (заблокировано со вторника)

### Блокеры
- Ожидание согласования юристов для партнёрской интеграции

### На следующей неделе
- Запуск аналитической инструментации
- 1:1 с тимлидом

---

## Краткий апдейт для skip-level

1. **Топ-результат:** Фича поиска выкатилась в прод без единого отката.
2. **Главная сложность:** Партнёрская интеграция заблокирована на согласовании у юристов с вторника.
3. **Фокус следующей недели:** Запуск аналитической инструментации и 1:1 с тимлидом.
```

---

### Пример 2: Свободный текст с метриками

**Входные данные:**
```
Финализировал Q2 OKR-документ и представил команде в среду. После запуска A/B-теста конверсия выросла с 4.2% до 4.7%. Продолжаю работу над редизайном дашборда — дизайн-ревью планировалось в пятницу, но перенесли на следующую неделю. Жёстких блокеров нет. Следующая неделя: завершить редизайн дашборда, согласовать ценовое предложение с финансами.
```

**Результат:**
```markdown
## Статус-отчёт — Неделя 9 июня

### Выполнено
- Финализировал Q2 OKR-документ и представил команде
- Запущен A/B-тест — конверсия выросла с 4.2% до 4.7%

### В работе
- Редизайн дашборда — дизайн-ревью перенесено на следующую неделю

### Блокеры
- Блокеров нет

### На следующей неделе
- Завершить редизайн дашборда
- Согласовать ценовое предложение с финансами

---

## Краткий апдейт для skip-level

1. **Топ-результат:** A/B-тест запущен — конверсия выросла с 4.2% до 4.7%.
2. **Главная сложность:** Дизайн-ревью по дашборду перенесено на следующую неделю.
3. **Фокус следующей недели:** Завершение редизайна дашборда и согласование ценового предложения с финансами.
```

## Триггеры

Любая из следующих фраз активирует скилл:

| Английский | Русский |
|------------|---------|
| Write my weekly status report | Напиши мой еженедельный статус-отчёт |
| Weekly status report | Еженедельный статус-отчёт |
| Turn my notes into a status report | Преобразуй мои заметки в отчёт |
| I need to send my weekly update to my manager | Мне нужно отправить еженедельный апдейт менеджеру |
