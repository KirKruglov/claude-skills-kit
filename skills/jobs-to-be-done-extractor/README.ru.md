# Jobs-to-be-Done Extractor

Извлекает структурированные JTBD-утверждения из папки с custdev-транскриптами и заметками интервью. Скил читает несколько md/txt файлов, синтезирует кросс-файловые паттерны и формирует JTBD-карту с доказательной базой и рангом по частоте — готовую для роадмап-сессий и приоритизации.

## Кому полезен

Продакт-менеджерам и UX-исследователям, у которых накопилось 3–15 файлов интервью, и нужно превратить сырые заметки в структурированные утверждения о мотивации пользователей без ручного синтеза.

## Требования

- Папка с custdev-транскриптами или заметками интервью (форматы .md или .txt)
- Минимум 1 файл; оптимально 3–15 для значимого частотного анализа
- Файлы должны содержать качественный текст (цитаты, заметки, открытые ответы) — не только числовые оценки

## Как использовать

1. Активируй скил (см. триггеры ниже)
2. Укажи Claude папку с custdev-файлами
3. Получи JTBD-карту: ранжированные утверждения, цитаты-доказательства, источники, метки уверенности и секцию «Паттерны и пробелы»

## Примеры

**Пример 1 — После серии пользовательских интервью:**
> "Извлеки JTBD из интервью"

Claude читает все файлы из папки, кластеризует сигналы мотивации и возвращает ранжированную JTBD-таблицу с цитатами и секцией паттернов.

**Пример 2 — Подготовка к роадмап-сессии:**
> "Синтез custdev заметок — у меня 8 файлов транскриптов в /research/q2-custdev/"

Claude обрабатывает все 8 файлов, присваивает уверенность High/Medium/Low по кросс-файловой частоте и выдаёт карту, которую можно вставить прямо в документ роадмап-планирования.
