# Campaign Retrospective Writer — Руководство пользователя

Узнайте, как превратить сырые данные кампании в структурированный маркетинговый разбор с помощью Campaign Retrospective Writer.

---

## Быстрый старт

Вот самый быстрый способ получить ретро:

1. Завершите кампанию и соберите имеющиеся метрики или заметки
2. Напишите: `напиши ретро по кампании` и вставьте данные
3. Получите шестисекционный Markdown-документ: цель vs. факт, каналы, что сработало/нет, рекомендации и строка тренда

**Результат:** Структурированный документ, готовый к отправке команде или руководителю.

**Время:** ~3 минуты

---

## Сценарии

### Сценарий 1: Подведение итогов email-рассылки для команды

**Ситуация:**
Вы маркетинг-менеджер. Квартальная рассылка только что завершилась. У вас есть цифры из сервиса рассылок (open rate, CTR, отписки) и несколько заметок по A/B-тесту тем. Нужно отправить быстрый ретро команде до старта следующей кампании.

**Что делать:**

1. Откройте сервис рассылок и скопируйте метрики кампании
   - Включите: open rate, CTR, процент отписок, размер базы
   - Добавьте результаты A/B-теста и качественные наблюдения обычным текстом

2. Запустите скилл: напишите `напиши ретро по кампании`
   - Вставьте метрики и заметки
   - Если не указали цель или период — скилл спросит одним коротким сообщением

3. Изучите результат
   - Проверьте таблицу **Цель vs. Факт** — корректно ли отражены плановые и фактические значения?
   - Прочитайте **Что сработало / Что не сработало** — совпадают ли гипотезы с вашим ощущением?
   - Отредактируйте **Строку тренда** под внутренние соглашения о названиях

4. Поделитесь с командой
   - Скопируйте Markdown в Notion, Confluence или Slack
   - Раздел **Рекомендации** сразу даёт команде список действий для следующей кампании

**Ожидаемый результат:**

Чистый шестисекционный ретро с оценкой по каналам, анализом с гипотезами и однострочной записью тренда. Команда получает выводы за 5 минут — без слайдов и таблиц.

**Почему это работает:** Вместо написания ретро с нуля (30–60 мин) вы вставляете сырые данные и получаете структурированный документ мгновенно. Гипотезы помечены, чтобы команда понимала, что подтверждено, а что — предположение.

### Сценарий 2: Разбор платной кампании перед планированием следующей

**Ситуация:**
Вы growth lead в стартапе. Платная кампания по лидогенерации (Facebook + Instagram) только что завершилась. У вас есть CPL, объём лидов, заметки по перформансу креативов и бюджет. Через два дня — планёрка по решению о масштабировании этого канала. Нужен краткий ретро для встречи.

**Что делать:**

1. Соберите данные кампании
   - Выгрузите CPL, количество лидов, потраченный бюджет из рекламного кабинета
   - Отметьте, какие креативы сработали, а какие нет
   - Добавьте контекстные заметки (усталость аудитории, сезонность, проблемы лендинга)

2. Напишите: `разбор кампании` и вставьте всё
   - Бросайте данные без форматирования — скилл работает с неструктурированным вводом
   - Укажите цель кампании (например, «500 лидов при CPL ≤ 20$»)

3. Изучите разделы **Разбор по каналам** и **Рекомендации**
   - Вердикт ✅/❌ по каждому каналу сразу показывает, что масштабировать, а что отключить
   - Фреймворк **Повторить / Изменить / Убрать** напрямую ложится в решения по бюджету

4. Принесите ретро на планёрку
   - Поделитесь ссылкой на документ или вставьте таблицу **Цель vs. Факт** в презентацию
   - Используйте **Строку тренда** как единственную запись в трекере кампаний

**Ожидаемый результат:**

Ретро, готовый к принятию решений: вердикты по каналам и конкретные рекомендации. Планёрка начинается с общего понимания данных — без разночтений.

**Почему это работает:** Раздел **Рекомендации** структурирует вопрос «что делаем дальше» до начала встречи, экономя 20+ минут обсуждения.

### Сценарий 3: Создание архива кампаний за квартал

**Ситуация:**
Вы контент-лид. За Q2 прошли три кампании: серия email-рассылок, органический контент в LinkedIn и вебинар. Перед планированием Q3 нужно собрать лёгкий архив выводов. Данные разбросаны по Slack, таблицам и памяти.

**Что делать:**

1. Запустите скилл три раза — по одному на каждую кампанию
   - Для каждой вставьте то, что есть: сообщения из Slack, строки из таблицы, краткое описание
   - Скилл работает с частичными данными; пропуски помечает как «н/д»

2. Используйте **Строку тренда** из каждого ретро
   - Соберите три строки в один документ «Итоги Q2»
   - Пример архива:
     ```
     Email Q2: CTR 2,4%, +0,4pp к цели — A/B тем был ключевым драйвером
     LinkedIn Q2: 12 лидов, CPL 3700₽ — органика не окупается; нужен платный буст
     Вебинар Q2: 180 регистраций, явка 62% — формат работает; повторить
     ```

3. Поделитесь архивом до Q3-планирования
   - Одна страница, три ретро, понятная картина приоритетов по каналам

**Ожидаемый результат:**

Три структурированных ретро и однострочный тренд-архив. Q3 начинается с данных, а не с догадок.

**Почему это работает:** Строка тренда создана именно для этого сценария — одна строка на кампанию, которая остаётся читаемой даже при росте архива.

## Советы

### Совет 1: Вставляйте всё — скилл работает с хаотичным вводом

Не нужно форматировать данные перед вставкой. Сырые цифры из таблицы, пересказ Slack-треда, буллеты с пост-мортем-колла — всё подойдёт. Скилл извлекает то, что может, и помечает пропуски как «н/д». Хорошее ретро из несовершенных данных лучше, чем никакого.

### Совет 2: Проверяйте и уточняйте гипотезы

Скилл помечает каждую причинно-следственную связь как **(гипотеза)**. Это намеренно — ретро часто путают корреляцию с причинностью. Проверьте гипотезы: подтверждённые данными — снимите метку, опровергнутые — исправьте. Пометка становится сигналом качества для команды.

### Совет 3: Используйте Строку тренда как живой трекер

Копируйте **Строку тренда** из каждого ретро в один документ (Notion, Confluence, Google Doc). После 4–6 кампаний паттерны становятся видны: какие каналы стабильно выполняют план, где растёт CPL, какие форматы побеждают снова и снова. Строка достаточно короткая, чтобы весь квартал помещался в один экран.
