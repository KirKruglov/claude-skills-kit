# Чек-лист месячного закрытия и подготовка к сверке — Руководство пользователя

Как максимально эффективно использовать скил при закрытии каждого месяца.

---

## Быстрый старт

Самый короткий путь к закрытию месяца:

1. Экспортируйте или скопируйте транзакции за месяц из банка (CSV-строки или таблица Markdown)
2. Напишите: «Чек-лист месячного закрытия» и вставьте транзакции + одно предложение контекста (тип субъекта + валюта)
3. Получите три готовых раздела: чек-лист, черновик категоризации и резюме для бухгалтера/инвестора

**Результат:** Структурированный пакет закрытия, готовый к отправке бухгалтеру или вставке в ежемесячный апдейт.

**Время:** ~3 минуты

---

## Сценарии

### Сценарий 1: ИП на УСН 6% готовит данные для КУДиР после закрытия месяца

**Ситуация:**
Вы ИП на УСН 6% (доходы). В конце каждого месяца нужно обновить КУДиР данными о доходах, сверить остаток по банку и проверить, не подходит ли срок авансового платежа. На руках — выгрузка из Тинькофф или Сбера в CSV.

**Что делать:**

1. Скачайте выгрузку за месяц из интернет-банка (обычно CSV с полями: дата, контрагент, сумма прихода, сумма расхода)
   - Не нужно чистить или переформатировать файл заранее — скил разберётся сам

2. Активируйте скил фразой: «Чек-лист месячного закрытия»
   - Вставьте CSV-строки в сообщение
   - Добавьте контекст: «ИП, УСН 6%, рубли, консалтинг и продажа курсов»

3. Просмотрите вывод и обновите КУДиР
   - Чек-лист содержит конкретное напоминание об обновлении столбца «Доходы» в КУДиР
   - В черновике категоризации видна итоговая сумма дохода для переноса в КУДиР
   - В резюме для бухгалтера перечислены спорные позиции, которые нужно разобрать до записи в КУДиР

4. Отработайте напоминание об акте сверки
   - Если есть непогашенная дебиторка — чек-лист пометит необходимость акта сверки с ключевыми контрагентами
   - Возьмите имена контрагентов из таблицы категоризации и инициируйте сверку при необходимости

5. Проверьте срок авансового платежа
   - В чек-листе указан ближайший квартальный срок (Q1: 28 апр, Q2: 28 июл, Q3: 28 окт)
   - Если месяц закрывается рядом со сроком — запланируйте платёж до завершения чек-листа

**Что вы получаете:**

- **Чек-лист** с пунктами, специфичными для ИП: обновление КУДиР, акт сверки, срок авансового платежа, сверка по банку
- **Правила категоризации** — таблица с русскими названиями категорий и флагами `⚠ DISPUTED` для неясных платежей
- **Резюме для бухгалтера** — итоги в рублях по категориям, список спорных позиций, открытые вопросы
- **Резюме для инвестора** — 3 предложения на понятном языке для ежемесячного отчёта

**Почему это работает:** Скил знает об обязательствах ИП на УСН и автоматически добавляет их в чек-лист. Вам не нужно держать в голове каждый регуляторный шаг — они уже в выводе, адаптированном под ваш тип субъекта.

### Сценарий 2: Фриланс-консультант закрывает месяц перед передачей бухгалтеру

**Ситуация:**
Вы фриланс-дизайнер, работаете как самозанятый или ИП. В конце месяца отправляете бухгалтеру сводку транзакций с пометками по непонятным позициям. Обычно это занимает 30–45 минут. На руках — CSV из банка за май и несколько транзакций, которые вы не знаете как классифицировать.

**Что делать:**

1. Выгрузите банковскую выписку за май в CSV
   - Включите все доступные колонки (дата, описание/контрагент, списание, зачисление)
   - Не нужно предварительно приводить в порядок — скил справится с нестандартными заголовками

2. Активируйте скил фразой: «Чек-лист месячного закрытия»
   - Вставьте CSV-строки в сообщение
   - Добавьте одну строку контекста: «ИП, рубли, ретейнеры за дизайн и проектные сборы»

3. Просмотрите черновик категоризации
   - Найдите строки с флагом `⚠ DISPUTED`
   - Добавьте пометку для бухгалтера рядом с каждой спорной позицией (например: «это личный перевод — игнорировать»)
   - Подтвердите предложенные категории или исправьте там, где нужно

4. Используйте резюме для бухгалтера как сопроводительное письмо
   - Скопируйте раздел резюме и вставьте в письмо бухгалтеру
   - Прикрепите исходный CSV; резюме даст бухгалтеру контекст до открытия файла

5. Пройдитесь по чек-листу
   - Чек-лист показывает, что именно нужно проверить перед тем, как можно считать месяц закрытым
   - Отмечайте пункты по мере выполнения

**Что вы получаете:**

- **Чек-лист** с 8–10 пунктами, включая 1–2 кастомных пункта по вашим спорным транзакциям
- **Таблица категоризации** — каждая транзакция с предложенной меткой и статусом
- **Резюме для бухгалтера** — итоги доходов/расходов по категориям, список спорных позиций, открытые вопросы
- **Резюме для инвестора** — 3 предложения на понятном языке для писем клиентам или инвесторам

**Почему это работает:** Вместо того чтобы вручную сортировать транзакции и писать пояснительную записку с нуля, вы получаете структурированный пакет за секунды. Ваш бухгалтер получает ровно ту информацию, которая ему нужна, без неразобранных «стопок» на потом.

### Сценарий 3: Со-основатель готовит финансовый снепшот для инвесторов

**Ситуация:**
Вы со-основатель небольшого ООО. У вас нет финансового директора. Каждый месяц инвесторы ждут краткого финансового апдейта по email. Список транзакций за месяц есть, но превращение сырых чисел в читаемый нарратив для инвестора занимает у вас час каждый раз.

**Что делать:**

1. Экспортируйте или скопируйте транзакции за месяц из банка
   - Любой формат: CSV, диапазон таблицы или простой список с датой, контрагентом и суммой

2. Активируйте скил фразой: «Помоги закрыть месяц» или «Подготовь данные для инвестора»
   - Вставьте транзакции и добавьте 2–3 предложения контекста:
     «ООО, рубли, SaaS-подписки + профессиональные услуги. Ежемесячная выручка ~1,5 млн ₽. Основные расходы: ФОТ, серверы, банковские комиссии.»

3. Сначала просмотрите раздел «Резюме для инвестора»
   - Скил генерирует абзац на 3–5 предложений с выручкой, денежной позицией и ключевыми рисками
   - Отредактируйте, если есть контекст, которого у скила нет (например, крупная сделка, закрытая уже после конца месяца)

4. Проверьте точность резюме для бухгалтера
   - Убедитесь, что итоги доходов и расходов совпадают с вашими ожиданиями
   - Подтвердите или скорректируйте спорные позиции

5. Отправьте инвесторский апдейт
   - Вставьте «Резюме для инвестора» в ваш шаблон письма инвесторам
   - Приложите «Резюме для бухгалтера» как расшифровку для тех, кто хочет детали

**Что вы получаете:**

- Готовый к вставке абзац-нарратив для инвесторского письма
- Итоги доходов/расходов по категориям с флагами спорных позиций
- Чек-лист для проверки перед финализацией месяца

**Почему это работает:** Раздел «Резюме для инвестора» написан для читателя без бухгалтерского образования. Скил берёт категоризированные цифры и превращает их в 3–5 предложений, которые рассказывают финансовую историю месяца — без жаргона, без формул, без необходимости писать это самостоятельно.

## Советы

### Совет 1: Всегда добавляйте контекст бизнеса в первое сообщение

Скил адаптирует вывод (пункты чек-листа, названия категорий, напоминания для ИП) на основе типа субъекта, который вы указываете. Без контекста — вывод будет в универсальном формате, без специфичных для ИП пунктов (КУДиР, авансовые платежи).

**Совет профи:** Сохраните одну строку-шаблон для ежемесячного сообщения: «ИП, УСН 6%, рубли, консалтинг» — вставляйте её каждый раз вместе с CSV.

### Совет 2: Не нужно чистить CSV перед вставкой

Банковские выгрузки часто содержат нестандартные названия колонок («Дата операции», «Сумма дебета», «Merchant ID»). Скил определяет колонки эвристически и перечисляет найденное соответствие в преамбуле. Исправить его проще там, чем переформатировать весь файл вручную.

**Совет профи:** Если скил определил колонки неверно, добавьте уточнение в сообщение: «Колонка 3 — сумма (плюс = доход, минус = расход)» — скил применит эту подсказку.

### Совет 3: Используйте флаг «DISPUTED» как список вопросов для бухгалтера

Каждая строка с `⚠ DISPUTED` автоматически становится открытым вопросом для вашего бухгалтера. Не нужно разбираться с ними самостоятельно до передачи — отправьте черновик категоризации с флагами как есть и дайте бухгалтеру принять финальное решение. Это экономит ваше время и оставляет решение тому, кто знает ваши правила учёта.

**Совет профи:** Скопируйте раздел «Спорные позиции» из резюме для бухгалтера в Telegram-чат с бухгалтером или в заметки — это готовый список конкретных вопросов без лишних слов.
