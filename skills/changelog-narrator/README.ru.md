# Changelog Narrator

Сравни две версии бизнес-документа и получи структурированный, читаемый changelog — без git, без командной строки, без «Отслеживания изменений».

Для менеджеров, продактов, операционных руководителей и фрилансеров, которые получают обновлённые версии документов и хотят быстро понять, что изменилось, — не перечитывая оба файла.

---

## Требования

- Два файла в рабочей папке Cowork (формат `.md` или `.txt`)
  - Старая версия (v1) и новая версия (v2) одного и того же документа
  - Подходит для: PRD, SOP, стратегических документов, договоров, протоколов встреч, регламентов, брифов
- Дополнительные настройки, API-ключи или инструменты не нужны

---

## Как использовать

1. Разместите обе версии документа в рабочей папке Cowork (или загрузите их)
2. Произнесите одну из триггерных фраз ниже и укажите имена файлов (или позвольте Claude найти их самостоятельно)
3. Claude определяет, какой файл v1, а какой v2 — по имени файла; если неоднозначно, уточнит
4. Claude сравнивает оба документа по разделам и формирует структурированный changelog
5. Изучите changelog: Резюме → Добавлено → Удалено → Изменено → Примечания

---

## Примеры

**Пример 1: Сравнение двух черновиков PRD**

> «Что изменилось между версиями?» + загружает `prd-v1.md` и `prd-v2.md`

Claude определяет `prd-v1.md` как старую версию, читает оба файла и выдаёт changelog: Резюме («Скоуп сужен с 5 до 3 сегментов; раздел Success Metrics полностью переписан; добавлено 2 риска»), Добавлено (раздел «Реестр рисков» с 2 новыми записями), Удалено (пункт «Мобильное приложение» из Out of Scope), Изменено («Срок: Q2 → Q3», «Целевая метрика: 10% → 15% retention»).

**Пример 2: Сравнение двух версий SOP с фокусом на раздел**

> «Сравни только раздел Эскалации в этих двух файлах» + `sop-draft.md` и `sop-final.md`

Claude читает оба файла, фильтрует до раздела «Эскалация» и выдаёт changelog только по нему. В примечаниях указано: «Сравнение ограничено разделом: Эскалация».

## Что скил делает и не делает

**Делает:**
- Сравнивает два `.md` или `.txt` файла по разделам
- Классифицирует изменения: Добавлено, Удалено, Изменено
- Описывает суть изменений простым языком — без git diff синтаксиса
- Обрабатывает таблицы (сравнивает строки по отдельности)
- По запросу ограничивает сравнение одним разделом
- Фиксирует допущения о порядке версий в разделе Примечания

**Не делает:**
- Не генерирует визуальный или side-by-side diff (для этого используйте Diffchecker.com)
- Не работает с `.docx`, `.pdf` и бинарными файлами
- Не сравнивает более двух документов за один запуск
- Не отслеживает автора изменений или время правки (без git нет метаданных)
