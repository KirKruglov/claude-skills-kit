# Data Room Prep Checklist

Подготовьте документы к фандрайзингу с адресным чек-листом due diligence, структурой папок и анализом пробелов — без SaaS и интеграций.

---

## Обзор

Data Room Prep Checklist генерирует пакет подготовки для основателей, входящих в due diligence seed или Series A раунда. По стадии раунда и бизнес-модели скилл формирует приоритизированный чек-лист по шести категориям (Юридическое, Финансы, Продукт, Команда, Коммерческое, Кэп-тейбл), готовую к копированию структуру папок для Google Drive или Notion, а также список пробелов: что скорее всего отсутствует и какие вопросы инвестор задаст следующими. Используйте этот скилл, когда получили term sheet и нужно организовать документы, при подготовке к первой встрече с VC, или чтобы проверить текущий data room перед началом формального процесса.

---

## Требования

- Стадия раунда (pre-seed / seed / Series A / Series B+)
- Тип бизнес-модели (SaaS / маркетплейс / hardware / услуги / другое)
- Опционально: тип инвестора (VC / angel / стратег / family office)
- Опционально: вставленный список документов из текущего data room — включает режим gap-анализа

Внешние инструменты, CRM и интеграции не нужны.

---

## Как использовать

1. **Определите контекст раунда**
   - Знайте вашу стадию (или примерную) и тип бизнеса
   - По желанию скопируйте список документов, которые уже есть в вашем data room

2. **Запустите скилл, написав:**
   - «Чек-лист дата рума для seed раунда»
   - «Подготовка data room для Series A»
   - Или по-английски: «Data room checklist for my seed round»

3. **Предоставьте контекст**
   - Укажите стадию и бизнес-модель в одном сообщении
   - По желанию вставьте список существующих документов для gap-анализа

4. **Получите пакет**
   - Чек-лист с метками приоритета: Обязательно / Ожидается / Желательно
   - Структуру папок, готовую к развёртыванию в Google Drive или Notion
   - Список пробелов с наиболее вероятными отсутствующими документами и предсказуемыми вопросами инвестора

## Примеры

### Пример 1: Подготовка seed-раунда (SaaS)

**Ввод:**
```
Готовлюсь к seed-раунду, B2B SaaS, привлекаем от VC.
```

**Вывод (фрагмент):**
```markdown
# Чек-лист data room — Seed · B2B SaaS
> Для: VC / институциональный инвестор

## Чек-лист due diligence

### Юридическое и корпоративное
- [ ] **[Обязательно]** Свидетельство о регистрации / учредительные документы
- [ ] **[Обязательно]** Кэп-тейбл (fully diluted, актуальный)
- [ ] **[Ожидается]** Акционерное соглашение
- [ ] **[Ожидается]** Договоры уступки ИС (все фаундеры)
- [ ] **[Желательно]** Опционная программа / ESOP

### Финансы
- [ ] **[Обязательно]** Финансовая модель на 3 года (P&L, денежный поток, баланс)
- [ ] **[Обязательно]** Разбивка MRR — последние 12 месяцев (помесячно)
- [ ] **[Ожидается]** Выписки по счёту — последние 3–6 месяцев
...

## Список пробелов

### Что скорее всего отсутствует (Seed)
1. Подписанные договоры уступки ИС со всеми фаундерами
2. Решения совета директоров по ранее выданным опционам
3. Список референс-клиентов с разрешением на контакт

### Что инвестор спросит следующим
1. «Покажите MRR по месяцам за последние 12 месяцев»
2. «Кто ваши 3 референс-клиента, можем ли мы с ними поговорить?»

**Следующий шаг:** Отправьте эту структуру папок юристу и убедитесь, что все юридические документы — подписанные оригиналы, а не черновики.
```

### Пример 2: Gap-анализ существующего data room

**Ввод:**
```
Series A раунд, маркетплейс. Вот что уже есть:
- Устав
- Кэп-тейбл (Excel)
- Финансовая модель на 2 года
- Биографии команды
- Питч-дек
```

**Вывод (фрагмент):**
```markdown
# Чек-лист data room — Series A · Маркетплейс
> Режим gap-анализа — сравнение с требованиями Series A

## Чек-лист — сравнение

### Юридическое и корпоративное
- ✓ Устав / учредительные документы
- ✓ Кэп-тейбл (уточните: fully diluted с post-money проекцией?)
- ✗ Акционерное соглашение — отсутствует
- ✗ Договоры уступки ИС (все фаундеры) — отсутствует
- ✗ Решения совета директоров по опционам — отсутствует

### Финансы
- ⚠ Финансовая модель на 2 года — есть, но Series A требует 3 года + unit economics
- ✗ Разбивка MRR по месяцам (последние 12 месяцев) — отсутствует
- ✗ Выписки по счёту (последние 3–6 месяцев) — отсутствует
...

### Что инвестор спросит следующим
1. «Можете поделиться данными по когортному удержанию?»
2. «Какой GMV и take rate по месяцам?»
```
