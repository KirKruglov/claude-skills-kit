# Fundraise Pipeline Tracker

Превращает сырые заметки по инвесторам в структурированный тиерный пайплайн с приоритетами follow-up — за секунды.

---

## Обзор

Fundraise Pipeline Tracker собирает структурированную воронку инвесторов из вставленных заметок и контекста раунда, решая проблему «декея пайплайна»: к третьей неделе фандрайза строки трекинг-таблицы протухают и основатель теряет, где остановился с каждым инвестором. Скил классифицирует каждого инвестора по Tier 1/2/3, извлекает детали (статус, следующий шаг, «что зашло», фидбэк) и формирует приоритизированный список «Требует внимания» — отдельно просроченные next-step и инвесторов, которые замолчали. Без CRM и интеграций — работает целиком из вставленного текста. Двуязычный EN/RU.

Используй этот скил, когда хочешь быстро получить снапшот статуса раунда, перед созвоном с инвесторами чтобы понять кому звонить в первую очередь, или когда трекинг-таблица устарела и нужно восстановить её из заметок.

---

## Требования

- Заметки по инвесторам в любом формате — свободный текст, заметки по встречам, переписка, списки
  - Минимум: имя инвестора + сигнал статуса
  - Оптимально: имя, фонд, дата последнего контакта, текущий статус, полученный фидбэк
- Необязательно: контекст раунда (стадия, целевая сумма, таймлайн)
- Не нужны никакие сторонние инструменты, интеграции или загрузка файлов

---

## Как использовать

1. **Собери заметки по инвесторам**
   - Собери заметки по встречам, резюме переписки или список инвесторов со статусами
   - Вставь всё в одно сообщение — скил обрабатывает любой формат

2. **Активируй скил фразой:**
   - «Pipeline инвесторов» или «Трекинг раунда»
   - На английском: «Fundraise pipeline» или «Track my investors»

3. **При желании добавь контекст раунда**
   - Укажи стадию (seed, Series A), целевую сумму и таймлайн
   - Без контекста скил тоже работает — поля шапки будут показывать «—»

4. **Просмотри результат**
   - Получи markdown-документ из трёх разделов: Таблица пайплайна → Детали по инвестору → Требует внимания
   - Используй список «Требует внимания» для планирования дня: кому писать, кому отправить материалы, кто замолчал

## Примеры

### Пример 1: Восстановление устаревшего пайплайна из заметок

**Вводные:**
```
Seed-раунд, цель $1.5M. 6 инвесторов в работе.

Jane Smith / Acme Ventures — интро-звонок 5 июня, follow-up 12 июня, просила cap table и фин.модель. Очень заинтересована, сильный PMF-сигнал. Cap table так и не отправил.

Ivan Petrov — бизнес-ангел, познакомились на demo day 10 июня. Понравился продукт. Написал follow-up 13 июня, ответа нет.

Startup Fund / Mark Lee — интро назначено на 25 июня. Ещё не встречались.

GreenLight VC — отказали. Сказали, слишком ранняя стадия.

Sarah Johnson / Builder Capital — первая встреча 3 июня. Сказала, надо обсудить внутри. Обновлений с 3 июня нет.

Alex / TechAngels — встречались 8 июня. Заинтересован, но чек $50k — ниже нашего минимума.
```

**Результат:**
```markdown
# Воронка инвесторов — Seed-раунд
**Дата отчёта:** 23 июня 2026
**Раунд:** Seed | **Цель:** $1.5M | **Таймлайн:** —
**Инвесторов:** 6 | **Tier 1:** 1 | **Tier 2:** 2 | **Tier 3:** 3 | **Требует внимания:** 3

## Требует внимания

### 🔴 Просроченные next-step
1. **Jane Smith (Acme Ventures)** — Отправить cap table + фин.модель. Просрочено (не отправлено после встречи 12 июня).

### 🟡 Потерял ответ
2. **Sarah Johnson (Builder Capital)** — Нет обновлений 20 дней. Последний контакт: 3 июня. Написать check-in.
3. **Ivan Petrov** — Нет ответа 10 дней. Последний контакт: 13 июня. Написать follow-up.
```

### Пример 2: Быстрый статус по середине раунда

**Вводные:**
```
Series A, $3M. Декабрьский закрытие.

Фонд «Рост» / Алексей Иванов — встречались 10 июня. Сильный интерес, запросили данные по юнит-экономике. Отправил данные 15 июня. Жду ответа.

**Инвесторов:** 3 | **Tier 1:** 2 | **Tier 2:** 1 | **Tier 3:** 0 | **Требует внимания:** 1

## Требует внимания

### 🟡 Потерял ответ
1. **Анна Соколова** — Нет ответа 18 дней. Последний контакт: ~5 июня. Отправить follow-up.
```

## Триггеры

Используй любую из этих фраз для активации скила:

| Английский | Русский |
|------------|---------|
| Fundraise pipeline | Pipeline инвесторов |
| Track my investors | Трекинг раунда |
| Who should I follow up with | Кому пора следить по инвесторам |
| Show me my investor pipeline status | Покажи статус моей воронки инвесторов |
| Investor pipeline tracker | Статус воронки инвесторов |
