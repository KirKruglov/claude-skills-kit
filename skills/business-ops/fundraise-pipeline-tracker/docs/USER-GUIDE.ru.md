# Fundraise Pipeline Tracker — Руководство пользователя

Как использовать Fundraise Pipeline Tracker, чтобы превратить сырые заметки по инвесторам в структурированный, готовый к действиям пайплайн.

---

## Быстрый старт

Самый быстрый способ получить пайплайн:

1. Вставь заметки по инвесторам — подходит любой формат (имена, статусы, резюме встреч)
2. Напиши: «Pipeline инвесторов» и вставь заметки
3. Получи тиерную таблицу пайплайна, детали по каждому инвестору и приоритизированный список «Требует внимания»

**Результат:** Структурированный пайплайн инвесторов, готовый к немедленному использованию.

**Время:** ~2 минуты

---

## Сценарии

### Сценарий 1: Еженедельный обзор пайплайна перед созвонами

**Ситуация:**

Ты фаундер в середине seed-раунда. Понедельник утром, на неделе три встречи с инвесторами. Твои трекинговые заметки разбросаны по черновикам в почте и Google Doc, который не обновлялся неделю. Тебе нужно понять, кто на какой стадии, кому надо отправить материалы и кто замолчал — до того, как начать звонить.

**Что делать:**

1. Открой свои заметки (почта, Google Doc, голосовые — всё, что есть)
   - Скопируй всё про каждого инвестора в одно сообщение
   - Не беспокойся о форматировании — буллеты, абзацы, мешанина языков — всё подойдёт

2. Активируй скил фразой: «Покажи статус моей воронки инвесторов»
   - Вставь все заметки одним сообщением
   - Добавь контекст раунда в начало, если есть: «Seed-раунд, цель $1M, хотим закрыть в сентябре»

3. Просмотри Таблицу пайплайна
   - Начни с Tier 1 — это горячие лиды; приоритизируй любые просроченные действия
   - Проверь Tier 2 на наличие ожидающих follow-up
   - Обрати внимание на Tier 3 — кого нужно re-engage, кого можно убрать

4. Работай по списку «Требует внимания»
   - Сначала отправь просроченные материалы (cap table, data room, фин.модель)
   - Напиши follow-up инвесторам, которые замолчали
   - Используй поля «Что зашло» и «Фидбэк» для персонализации каждого письма

**Ожидаемый результат:**

Получаешь markdown-документ из трёх разделов:
- **Таблица пайплайна:** Все инвесторы в одном виде с тиером, статусом, следующим шагом и фидбэком
- **Детали по инвестору:** Полный разбор по каждому для подготовки к звонкам
- **Требует внимания:** Просроченные задачи и замолчавшие инвесторы, отсортированные по срочности

Заходишь на каждый созвон зная, где стоишь с этим инвестором и что для него важно.

**Почему это работает:** Вместо того чтобы перечитывать разрозненные заметки перед каждым звонком, у тебя один чистый структурированный вид. Тратишь 10 минут на обзор вместо 45 минут на восстановление контекста.

### Сценарий 2: Восстановление устаревшего пайплайна после паузы

**Ситуация:**

Ты фаундер, который взял две недели паузы от активного фандрайза ради продукта. Трекинговая таблица полностью устарела — часть разговоров встала, часть инвесторов замолчала, и ты потерял кто где. Есть заметки по встречам и фрагменты переписки, но ничего структурированного. Нужно быстро восстановить картину кто ещё активен, прежде чем возобновлять аутрич.

**Что делать:**

1. Собери всё, что есть по каждому инвестору
   - Прогуляйся по папке «Отправленные» за последние 4–6 недель
   - Скопируй последнее письмо, которое ты отправил или получил от каждого инвестора
   - Добавь любые заметки, которые делал после встреч (даже неформальные)

2. Активируй скил: «Трекинг раунда»
   - Вставь весь сырой материал — куски писем, заметки по встречам, голосовые → текст
   - Скил справляется с неполной и непоследовательной информацией; пометит, чего не хватает

3. Начни с раздела «Потерял ответ»
   - Это инвесторы, от которых нет ответа 14+ дней
   - Приоритизируй re-engagement для Tier 1 и Tier 2, которые замолчали
   - Используй поля «Что зашло» и «Фидбэк» для составления релевантного check-in письма

4. Обновляй пайплайн по мере аутрича
   - После каждого разговора добавляй обновлённые заметки и перезапускай скил
   - Каждый запуск создаёт свежий снапшот на основе того, что вставишь

**Ожидаемый результат:**

Получаешь восстановленный пайплайн, который показывает:
- Кто из инвесторов всё ещё тёплый (Tier 1 / Tier 2 с недавней активностью)
- Кто замолчал и на сколько дней
- Какой последний известный статус, фидбэк и следующий шаг у каждого

Есть чёткая отправная точка для re-engagement без часа на восстановление истории.

**Почему это работает:** Скил обрабатывает грязные и неполные заметки и всё равно выдаёт полезную структуру. Даже частичной информации хватает для ориентировочного понимания, где стоит раунд.

### Сценарий 3: Подготовка статус-апдейта для сооснователя или ментора

**Ситуация:**

Ты фаундер, который занимается investor relations. Технический сооснователь должен понять статус фандрайза перед board call. Ты хочешь поделиться чистым обзором — не свалить сырые заметки, — чтобы сооснователь мог ответить на вопросы совета директоров о том, кто в пайплайне и какие следующие вехи.

**Что делать:**

1. Собери самые свежие заметки по инвесторам в одно сообщение
   - Включи всех в пайплайне вне зависимости от тира — скил сам структурирует
   - Добавь контекст раунда: стадия, цель, таймлайн, статус лида (если есть)

2. Напиши: «Pipeline инвесторов» и вставь заметки

3. Поделись результатом напрямую
   - Скопируй Таблицу пайплайна для верхнеуровнего вида
   - Включи список «Требует внимания» — покажет, что происходит дальше
   - Добавь Детали по инвестору только если сооснователю нужна глубина по конкретным именам

4. Просмотрите вместе
   - Используй тиеры и статусы как точки для обсуждения
   - Колонка «Фидбэк» показывает, что говорят инвесторы — полезный контекст для board call

**Ожидаемый результат:**

Делишься чистым markdown-документом, который сооснователь прочитает за 2 минуты:
- Кто в пайплайне и на какой стадии
- Что горячее (Tier 1), что нужно прогревать (Tier 2), что спекулятивное (Tier 3)
- Какие действия ожидаются и кто замолчал

**Почему это работает:** Вместо того чтобы устно проходиться по разрозненным заметкам, у тебя структурированный документ, который передаёт полную картину без получасового catch-up разговора.

## Советы

### Совет 1: Указывай даты, когда они есть

Скил использует даты для выявления инвесторов, которые замолчали (нет ответа 14+ дней). Если включить дату последнего контакта («встречались 12 июня», «написал 13 июня»), скил автоматически пометит тех, кто не ответил. Без дат — только тех, кого явно пометил как молчащих.

**Лайфхак:** Подходят даже приблизительные даты («встречались на прошлой неделе», «интро в начале июня»). Скил интерпретирует их и отметит неопределённость.

### Совет 2: Запускай еженедельно, а не один раз

Скил лучше всего работает как регулярный снапшот. Запускай в начале каждой недели с обновлёнными заметками — всегда будет актуальный вид пайплайна. Предыдущий результат — просто справка; каждый новый запуск создаёт свежий документ на основе того, что вставишь.

**Лайфхак:** Веди текущий «investor notes» документ в течение недели. Добавляй заметки после каждой встречи или переписки. В понедельник вставь весь документ и перезапусти скил.

### Совет 3: Используй колонку «Фидбэк» для персонализации follow-up

Скил извлекает, что сказал каждый инвестор — их опасения, что зашло, их вопросы. Используй это при написании follow-up писем. Сообщение, которое ссылается на «тревогу по чёрну, которую вы подняли» или «вопрос о размере рынка с прошлой встречи», работает несравнимо эффективнее дежурного check-in.

**Лайфхак:** Если колонка «Фидбэк» пустая для инвестора — это сигнал: либо встреча не выявила реальных возражений (хороший знак), либо ты их не зафиксировал. Вернись к заметкам и добавь конкретику, которую помнишь.
