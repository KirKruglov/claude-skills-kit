# Руководство пользователя: CSV Data Analyzer

Три реалистичных сценария использования скила CSV Data Analyzer. Технические знания не нужны.

---

## Быстрый старт

1. Убедись, что CSV-файл находится в рабочем пространстве Cowork (загрузи его или подтверди, что он в выбранной папке)
2. Напиши: **«Проанализируй CSV»** (или любую из фраз-триггеров из README)
3. Ответь на один вопрос о том, что ты хочешь понять
4. Прочитай инсайты — они написаны понятным бизнес-языком

Всё. Никакой настройки, кода и формул.

---

## Сценарий 1: Ежемесячный отчёт по продажам

**Ситуация:** Ты экспортировал данные за месяц из CRM в CSV. Хочешь узнать, какой регион и продукт показали лучшие результаты — но не хочешь открывать Excel и строить сводные таблицы.

**Что делать:**
1. Загрузи `sales-june.csv` в рабочее пространство Cowork
2. Напиши: «Проанализируй CSV»
3. Claude профилирует данные и спросит: «Что ты хочешь понять — сводная статистика, тренды во времени, топ/аутсайдеры, сравнение групп или что-то ещё?»
4. Ответь: «Какой регион принёс больше всего выручки?»
5. Claude вернёт ранжированную таблицу регионов по выручке с пояснением из 2 предложений

**Ожидаемый результат:**
```
### Ключевые инсайты
1. EMEA принёс 42% от общей выручки (1,2 млн $) — лучший показатель среди всех регионов.
2. APAC вырос на 18% по сравнению с предыдущим периодом, а AMER снизился на 7%.
3. Лучший регион (EMEA) превышает аутсайдера (LATAM) в 3,1 раза.
```

**Советы:**
- Можно задавать уточняющие вопросы: «Теперь покажи топ-3 продукта в EMEA»
- Если Claude не распознаёт название колонки из твоего вопроса — он уточнит. Просто ответь в свободной форме

## Сценарий 2: Аудит задач спринта

**Ситуация:** Через 2 дня конец спринта. Ты экспортировал доску задач в CSV и хочешь быстро понять, кто перегружен и что застряло в каком статусе.

**Что делать:**
1. Положи `sprint-tasks.csv` в выбранную папку Cowork
2. Напиши: «Что в этом CSV»
3. Claude покажет названия колонок и спросит, что ты хочешь понять
4. Ответь: «Как задачи распределяются по статусу и исполнителю»
5. Claude сгруппирует данные и выделит дисбалансы

**Ожидаемый результат:**
```
### Ключевые инсайты
1. 38% задач всё ещё в статусе «В работе» — до конца спринта 2 дня.
2. У Алексея 11 открытых задач — больше всех в команде. У Сары — 3.
3. Все заблокированные задачи (4 штуки) назначены на команду бэкенда.
```

**Советы:**
- Не нужно называть колонки точно — скажи «у кого больше всего задач» и Claude сам разберётся с колонкой исполнителя
- Используй предложенные follow-up направления для детализации блокеров или просрочек

## Сценарий 3: Результаты опроса

**Ситуация:** Ты провёл опрос из 20 вопросов и выгрузил ответы в CSV. Нужны ключевые цифры до встречи с командой через 30 минут.

**Что делать:**
1. Загрузи `survey-results.csv`
2. Напиши: «Помоги понять данные из таблицы»
3. На вопрос «что хочешь понять» ответь: «Сводная статистика и очевидные паттерны»
4. Claude профилирует каждую колонку, посчитает распределение ответов для закрытых вопросов и резюмирует паттерны в открытых

**Ожидаемый результат:**
```
### Ключевые инсайты
1. 78% респондентов оценили онбординг на 4 или 5 из 5.
2. Самая низкая оценка — «понятность документации»: средний балл 2,8/5.
3. В 12 из 45 ответах на открытый вопрос упоминается «долгая настройка» как проблема.
```

**Советы:**
- Если в опросе много колонок — скажи, на каком разделе сосредоточиться: «Смотри только вопросы про онбординг (колонки 5–9)»
- Открытые ответы Claude читает и обобщает — специальные NLP-инструменты не нужны

## Советы и лучшие практики

**Перед началом:**
- Убедись, что в CSV есть строка заголовков (первая строка = названия колонок)
- Для очень больших файлов (тысячи строк) Claude сделает выборку и сообщит об этом

**Как получить лучший результат:**
- Формулируй конкретно: «Какой продукт давал наибольшую среднюю сумму заказа?» работает лучше, чем «расскажи подробнее»
- Если определение типа колонки кажется неверным — уточни: «Колонка "выручка" в тысячах рублей, а не в рублях»
- Для данных с датами укажи название колонки явно: «Колонка с датами называется created_at»

**Когда Claude задаёт уточняющий вопрос:**
- Отвечай в свободной форме — технические термины не нужны
- Если не знаешь, что именно хочешь — скажи «что самое интересное в этих данных?» и Claude выберет наиболее значимые находки сам

**Ограничения:**
- Графики и визуализации в этом скиле недоступны — скопируй таблицу в Excel или Google Sheets для построения графиков
- Claude не изменяет и не перезаписывает исходный файл
- Файлы с более чем ~500 строками обрабатываются по выборке; для анализа полного датасета очень больших файлов рассмотри скил `data:analyze` (требует Claude Code)
