# Руководство пользователя: Prompt Library Curator

## Быстрый старт

1. Напишите одну из фраз: `организуй мои промпты`, `библиотека промптов` или `структурируй промпты`
2. Вставьте промпты — или укажите, в каком файле они находятся
3. Готово. Вы получаете структурированный каталог `prompt-library.md`

---

## Сценарий 1: Организация растущей коллекции промптов

**Ситуация:** Вы собираете промпты для Claude уже несколько месяцев — часть в заметках, часть в `.txt`-файле. Коллекция выросла до 30+ промптов, и найти нужное становится всё сложнее.

**Что делать:**
1. Скопируйте все промпты в один текстовый блок (разделите пустыми строками)
2. Напишите: *«организуй мои промпты»* и вставьте блок
3. Скил назначает категорию, 2–4 тега, краткое описание (до 10 слов) и уровень сложности каждому промпту
4. Вы получаете `prompt-library.md` с индексной таблицей и промптами, сгруппированными по категориям

**Ожидаемый результат:**
- Индексная таблица, отсортированная по категории и сложности
- Каждый промпт назван и отмечен тегами для быстрого поиска
- Дубли отмечены — вы решаете, какой оставить

---

## Сценарий 2: Создание командной библиотеки промптов

**Ситуация:** Вы готовите общий справочник промптов для команды. У вас есть файл `team-prompts.md` с 15 промптами, которые команда использует регулярно, но он не структурирован и без описаний.

**Что делать:**
1. Напишите: *«структурируй промпты — они в файле team-prompts.md»*
2. Скил читает файл, категоризирует и тегирует каждый промпт
3. Оригинальный текст промпта сохраняется без изменений

**Ожидаемый результат:**
- Структурированный каталог, готовый к отправке команде
- Быстрая навигация Quick Find (при >20 промптах)
- Промпты с переменными (`{{переменные}}`) автоматически помечаются тегом `template`

---

## Сценарий 3: Периодическое обновление библиотеки

**Ситуация:** Ваша библиотека промптов существует, но устарела — новые промпты добавлялись в конец без категоризации.

**Что делать:**
1. Вставьте только новые, некатегоризированные промпты
2. Напишите: *«разбери мою коллекцию промптов»*
3. Получите каталог для новой партии — и вручную объедините с существующей библиотекой

**Совет:** Вы можете запустить скил повторно на полной библиотеке в любое время, чтобы обновить индексную таблицу и пересмотреть дубли.

---

## Советы

- **Чётко разделяйте промпты** — пустые строки или `---` между промптами дают лучший результат разбивки
- **Сохраняйте переменные-плейсхолдеры** — промпты вида `"Подведи итог {{документа}} для {{аудитории}}"` определяются как шаблоны и автоматически помечаются тегом `template`
- **Не редактируйте промпты перед запуском** — вставляйте как есть; скил организует, не трогая формулировки
- **Используйте раздел Duplicates** — когда два промпта решают одну задачу, скил их отмечает, и вы решаете, что оставить или объединить

---

## Структура выходного файла

Скил создаёт `prompt-library.md` со следующей структурой:

```
# Prompt Library
Обновлено: YYYY-MM-DD | Всего промптов: N | Категорий: X | Дублей: Y

## Quick Find (при N > 20)
[Writing] · [Research] · [Coding] · ...

## Index (индексная таблица)
| # | Category | Summary | Tags | Complexity |

## Writing
### [Название промпта]
tags: ... | complexity: ...
[оригинальный текст промпта]

## Duplicates
[отмеченные дубли, или «No duplicates detected.»]
```
