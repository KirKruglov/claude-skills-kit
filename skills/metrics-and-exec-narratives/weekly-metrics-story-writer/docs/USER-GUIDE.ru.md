# Руководство пользователя — Weekly Metrics Story Writer

## Что делает этот скил

Каждую неделю вы копируете числа из дашборда и тратите 30–60 минут на то, чтобы превратить их в текстовое обновление для руководства или команды. Этот скил делает это за вас. Вставьте метрики, ответьте на два вопроса — получите готовый email или Slack-пост для копипаста.

---

## Быстрый старт

**Триггер:** Напишите одну из фраз, чтобы начать:
- «Недельный нарратив по метрикам»
- «Напиши нарратив по метрикам»
- «Метрики в email»
- Вставьте числа напрямую — скил их распознает

**Шаги:**
1. Вставьте метрики (любой формат)
2. Добавьте одну строку контекста: «В среду был инцидент» или «Ничего особого»
3. Укажите аудиторию и формат: «Руководство, email» или «Команда, Slack» или «Оба»
4. Получите готовый текст — скопируйте и отправьте

---

## Какой формат метрик принимается?

Любой текстовый формат. Примеры:

**Таблица:**
```
| Метрика           | Эта неделя | Прошлая неделя |
|-------------------|-----------|----------------|
| DAU               | 48 200    | 44 100         |
| 7-day Retention   | 34%       | 36%            |
```

**Список:**
```
DAU: 48 200 (было 44 100)
Retention: 34% (было 36%)
Выручка: 182 000 $ (было 175 000 $)
```

**CSV:**
```
DAU,48200,44100
7-day Retention,34%,36%
Выручка,182000,175000
```

**Свободный текст:**
```
DAU на прошлой неделе был 44к, на этой вырос до 48к. Retention немного упал с 36 до 34 процентов.
```

Все форматы дают одинаковое качество вывода. Приводить данные к единому виду не нужно.

---

## Выбор формата

**Email** — для обновлений руководству, еженедельных OKR-чекинов или любых письменных отчётов стейкхолдерам. Структурированный, деловой стиль, ≤ 200 слов.

**Slack** — для командных дайджестов, продуктовых апдейтов, любого канала, где нужен быстрый и сканируемый контент. Разговорный, использует Slack-разметку, ≤ 120 слов.

**Оба** — генерирует оба формата за один запуск. Удобно, если вы отправляете одно и то же обновление разным аудиториям.

---

## Добавление контекста

Контекст не обязателен, но значительно улучшает нарратив. Достаточно одной строки:

- «Запустили редизайн онбординга во вторник»
- «В среду был инцидент с поддержкой, исправили утром в четверг»
- «Идёт A/B тест на странице цен»
- «На этой неделе ничего особого»

Если пропустить контекст, скил напишет нарратив только по числам и не включит секцию «Контекст».

---

## Как читать результат

Финальный вывод состоит из двух частей:

**1. Нарратив** — ваш email или Slack-пост, готовый к копипасту. Без плейсхолдеров и скобок.

**2. Сводка сигналов** — компактная строка для ваших заметок:
```
Сводка сигналов:
🟢 DAU · 🟢 Выручка · 🔴 Retention · 🟡 Churn
```

Зелёный = хорошо, Красный = требует внимания, Жёлтый = без изменений.

---

## Советы

- **Добавляйте значение предыдущего периода** для каждой метрики, где это возможно. Без него скил не может показать динамику — нарратив всё равно будет написан, но без «вырос на 9%».
- **Называйте метрики конкретно.** «Пользователи» — неоднозначно; «DAU» или «Еженедельные активные пользователи» даёт скилу достаточно для точного предложения.
- **Одна строка контекста многое решает.** Даже «Ничего особого на этой неделе» помогает скилу не придумывать причины изменений.
- **Для регулярного использования** заведите шаблонный файл в Cowork со стандартным списком метрик и обновляйте значения каждую неделю перед запуском скила.

---

## Часто задаваемые вопросы

**Можно передать файл вместо вставки?**  
Да. Если в папке Cowork есть `.md`-файл с данными метрик, укажите путь: «Используй файл `/reports/week-22.md`» — скил прочитает его.

**Что если у меня 15 метрик?**  
Скил обработает все, но в нарратив попадут топ-5 по силе сигнала. Остальные войдут в сводку сигналов в конце.

**Что если я не знаю, что означают эти числа?**  
Скил пишет нарратив по направлению (рост / падение / стабильно) и названию метрики. Если интерпретация кажется неточной, добавьте строку контекста — вывод улучшится.

**Можно попросить другой тон?**  
Да. Напишите «более официально» или «менее формально» — скил применит этот тон без дополнительных уточнений.

**Скил сохраняет мои данные?**  
Нет. Метрики обрабатываются только в рамках текущей сессии и не сохраняются между сессиями.
