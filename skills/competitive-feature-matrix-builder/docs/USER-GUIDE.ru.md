# Руководство пользователя: Competitive Feature Matrix Builder

---

## Быстрый старт

1. Сохраните заметки о конкурентах как отдельные `.md` или `.txt` файлы в одну папку (один файл на конкурента)
2. Опционально добавьте `your-product.md` со списком фич вашего продукта для gap-сравнения
3. Скажите: **"Составь feature matrix по папке [путь к папке]"**
4. Получите таблицу Feature Matrix, раздел Gap Analysis и Рекомендации

---

## Сценарий 1: Подготовка к роадмап-сессии

**Ситуация:** Вы готовитесь к квартальному планированию роадмапа. Заметки по 4 конкурентам, собранные за последние недели, лежат в папке отдельными markdown-файлами. Нужна одна таблица, показывающая, какие фичи есть у каждого конкурента, и где ваш продукт отстаёт.

**Что делать:**

1. Откройте папку с заметками (например, `/research/q2-competitive/`). Убедитесь, что на каждого конкурента есть отдельный файл.
2. Добавьте в ту же папку файл `your-product.md` со списком фич вашего продукта.
3. Запустите скил:
   > "Составь feature matrix по папке /research/q2-competitive/"
4. Проверьте таблицу Feature Matrix — проверьте точность символов ✓/✗/?; при необходимости скорректируйте заметки.
5. Поделитесь разделом Gap Analysis с командой как основой для обсуждения роадмапа.

**Ожидаемый результат:** Готовый markdown-документ с полной матрицей и приоритизированной таблицей гэпов (Высокий / Средний / Низкий). Раздел Рекомендации — 2–4 конкретных пункта действий по выявленным пробелам.

**Совет:** Чем структурированнее ваши заметки (маркированные списки фич, чёткие заголовки), тем точнее извлечение. Неструктурированные заметки тоже работают — скил помечает низкоуверенные извлечения, чтобы вы могли проверить перед шарингом.

## Сценарий 2: Подготовка к продажной встрече

**Ситуация:** Ваш сейлз-отдел встречается с потенциальным клиентом, который рассматривает также двух конкурентов. Нужно быстрое сравнение: в чём ваши преимущества и какие пробелы нужно отработать в разговоре.

**Что делать:**

1. Соберите имеющиеся конкурентные заметки (даже черновые — из LinkedIn, продуктовых страниц, внутренних документов) в одну папку.
2. Запустите скил:
   > "Матрица фич конкурентов по папке /sales-intel/prospect-eval/"
3. В выводе посмотрите раздел **Ваши дифференциаторы** — это фичи, уникальные для вашего продукта.
4. Изучите **Высокоприоритетные гэпы** — фичи, которые есть у конкурентов, но нет у вас; будьте готовы отработать их в разговоре.
5. Скопируйте матрицу в свой документ подготовки к встрече.

**Ожидаемый результат:** Чёткая картина, где вы выигрываете (дифференциаторы) и где конкуренты имеют преимущество (гэпы), основанная на ваших собственных исследовательских заметках.

## Сценарий 3: Глубокий анализ одного конкурента

**Ситуация:** У вас пока заметки только по одному конкуренту, и вы хотите получить структурированный список фич перед тем, как добавлять остальных.

**Что делать:**

1. Положите заметки о конкуренте в папку (например, `/research/notion/`).
2. Запустите скил:
   > "Построй feature matrix по папке /research/notion/"
3. Скил сформирует список фич в одном столбце и укажет, что gap-анализ требует 2+ конкурентов.
4. Используйте извлечённый список фич как шаблон — добавьте файлы с заметками по другим конкурентам в ту же папку и запустите скил снова.

**Ожидаемый результат:** Нормализованный список фич одного конкурента, готовый к расширению. Скил укажет, чего не хватает (самосравнение, gap-анализ), чтобы вы знали, что добавить.

---

## Советы

- **Называйте файлы понятно:** Скил извлекает названия конкурентов из имён файлов (например, `hubspot-notes.md` → "Hubspot") или из первого `# Заголовка` в файле. Чёткие имена = чистые заголовки столбцов в матрице.
- **Используйте `your-product.md` для настоящего gap-анализа:** Без него скил строит только матрицу конкурентов. Добавьте список фич своего продукта, чтобы разблокировать разделы Gap Analysis и Рекомендации.
- **Неструктурированный текст тоже работает:** Если ваши заметки — сплошной текст без списков, скил использует извлечение на уровне предложений. Такие извлечения помечаются как низкоуверенные, чтобы вы могли проверить их перед шарингом.
- **Перезапускайте после обновления заметок:** Скил читает файлы заново каждый раз. Обновите заметки, запустите снова — получите актуальную матрицу за секунды.
