# Setup Wizard — руководство пользователя

Как пройти настройку сервиса и не потерять, на каком вы шаге.

---

## Быстрый старт

Самый быстрый способ запустить первый маршрут:

1. Скажите: «помоги настроить example.com» — или, если интерфейс поддерживает слэш-команды, `/setup-wizard https://example.com`
2. Ответьте на вопрос, чего вы хотите добиться (установить / подключить / настроить / починить / перенести)
3. Подтвердите строку задачи, которую вернёт скил
4. Посмотрите карту маршрута и идите по одному шагу, присылая запрошенные доказательства

**Результат:** Заявленная задача либо выполнена и подтверждена артефактом, либо вы получаете прямой ответ, что именно её заблокировало и какие есть варианты.

**Время:** 10–40 минут, в зависимости от сервиса

---

## Сценарии

### Сценарий 1: Установка инструмента, которым вы раньше не пользовались

**Ситуация:**
Команда выбрала новый сервис, и он нужен на вашем ноутбуке сегодня. На сайте документации десяток страниц, и непонятно, какие относятся к вашей ОС и вашему тарифу.

**Что делать:**

1. Начните со ссылки на сервис
   - «Помоги установить example-service — https://example-service.com»
   - Или, если поддерживаются слэш-команды: `/setup-wizard https://example-service.com`

2. Ответьте на вопрос о задаче
   - «Хочу установить с нуля на macOS и войти под рабочим аккаунтом»

3. Дайте уточнения
   - Скил спросит только то, что не выводится из ссылки: ОС, версия, как планируете использовать

4. Подтвердите формулировку
   - `Задача: установить example-service на macOS и войти под существующим рабочим аккаунтом`
   - Скажите «да» — до этого скил не пойдёт искать справку

5. Пройдите маршрут
   - В каждом шаге одно действие и указание, какой артефакт прислать
   - Присылайте точный вывод команды, а не его пересказ

**Ожидаемый результат:**

Маршрут из 3–5 шагов, последний — проверочный, затем:
```
[setup-wizard] ✅ Маршрут пройден: 4/4

Задача: установить example-service на macOS и войти под рабочим аккаунтом
Результат: достигнут
Подтверждено: вывод `svc auth status` с активным аккаунтом
За границей маршрута: настройки команды, интеграция с CI
```

**Почему это работает:** Маршрут строится по страницам, которые действительно соответствуют вашей задаче и вашей ОС, — вы не выполняете инструкцию для Linux на Mac и инструкцию для платного тарифа на бесплатном.

### Сценарий 2: Починка того, что перестало работать

**Ситуация:**
Интеграция, работавшая месяц назад, теперь падает с непонятной ошибкой. Вы уже вбили её в поиск и нашли пять противоречащих друг другу тредов на форуме.

**Что делать:**

1. Запустите скил со ссылкой на сервис и опишите поломку
   - «Интеграция Slack на example.com перестала доставлять сообщения, ошибка: `webhook_not_found`»

2. Подтвердите формулировку
   - `Задача: восстановить доставку сообщений из example.com в Slack, сейчас падает с webhook_not_found`

3. Идите по маршруту, который скил построит из официальных страниц по траблшутингу
   - Обычно: проверить текущую конфигурацию → проверить ключ → пересоздать подключение → проверить доставку

4. Если шаг падает — присылайте **полный** текст ошибки
   - Скил разбирает её внутри этого шага: `Шаг 2, попытка 1`, `Шаг 2, попытка 2`…
   - Номер шага не растёт, пока ошибка открыта

5. Если три попытки не помогли — прочитайте разбор
   - Вы получите: что известно, что исключено и 2–3 конкретных варианта, включая обращение в поддержку сервиса

**Ожидаемый результат:**

Либо интеграция снова работает и это подтверждено артефактом, либо у вас есть точная сводка с доказательствами, которую можно отдать поддержке, — это гораздо быстрее, чем начинать переписку с нуля.

**Почему это работает:** Потолок в три попытки останавливает бесконечный цикл «попробуй ещё вот это». Когда официальный путь исчерпан, вы получаете выбор, а не новые догадки.

---

### Сценарий 3: Задача оказалась невозможной на вашем тарифе

**Ситуация:**
Вы хотите включить функцию, которую видели на демо. Вы не знаете, что она доступна только на тарифе Business.

**Что делать:**

1. Назовите задачу как обычно
   - «Хочу включить SSO на example.com для команды»

2. Подтвердите формулировку и дайте скилу прочитать справку

3. Прочитайте сообщение об остановке
   ```
   [setup-wizard] 🛑 Официальной справки нет: SSO на тарифе Starter

   SSO в документации описан как функция тарифа Business. Строить маршрут
   бессмысленно, пока тариф не изменён. Варианты: повысить тариф,
   переформулировать задачу (например, «настроить 2FA для команды» —
   доступно на Starter) или написать в отдел продаж.
   ```

4. Переформулируйте задачу, если хотите продолжить с достижимой целью

**Ожидаемый результат:**

Вы узнаёте это за две минуты, а не после сорока минут блужданий по настройкам, в которых этой опции нет.

**Почему это работает:** Скил проверяет предусловия — тариф, права, зависимости — до построения маршрута и отказывается строить маршрут, который заведомо упрётся в тупик.

## Советы

### Совет 1: Давайте ссылку на сервис, а не на документацию

Скил ожидает аргументом сайт самого сервиса и находит нужные страницы справки сам, исходя из подтверждённой задачи. Если вы вставите страницу документации, он тоже сработает, но сначала уточнит, какой сервис имеется в виду.

**Лайфхак:** Если у сервиса есть репозиторий (у многих инструментов для разработки он есть), ссылка на репозиторий тоже подходит — официальный репозиторий считается официальной справкой.

### Совет 2: Присылайте артефакты, а не впечатления

«Вроде установилось» шаг не закрывает — скил переспросит и не увеличит номер шага. Вставляйте реальный вывод команды, полный текст ошибки или скриншот окна. Именно на этом держится достоверность финальной сводки: за каждым закрытым шагом стоит доказательство.

**Лайфхак:** Маскируйте токены, ключи и пароли перед отправкой. Если случайно прислали — скил скажет об этом и порекомендует отозвать ключ; сделайте это сразу, история чата не место для секретов.

### Совет 3: Держите задачу узкой

Один маршрут — одна задача. «Установить CLI, настроить команду и подключить к CI» — это три задачи, скил попросит выбрать одну. Узкие задачи дают короткие маршруты (2–3 шага), которые вы действительно доводите до конца.

**Лайфхак:** Закончив маршрут, просто запустите следующий для следующей задачи. Ссылка на сервис уже известна, второй маршрут стартует быстрее.
