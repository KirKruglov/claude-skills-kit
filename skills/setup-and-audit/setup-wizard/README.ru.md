# Setup Wizard

Пройдите настройку любого сервиса шаг за шагом — без угадывания и без брошенной на середине конфигурации.

---

## Обзор

Setup Wizard ведёт вас по задаче настройки внешнего сервиса или IT-инструмента: установка с нуля, подключение существующего аккаунта, настройка конкретной функции, починка сломавшегося, обновление или перенос. Сначала скил выясняет, чего вы хотите добиться, подтверждает формулировку задачи с вами, затем читает **официальную** справку сервиса именно под эту задачу и строит маршрут с фиксированным числом шагов.

Дальше он диктует по одному шагу за раз. Шаг закрывается только когда вы прислали доказательство — точный вывод команды, полный текст ошибки или скриншот. Слова «вроде получилось» шаг не закрывают. Все действия выполняете вы; скил не запускает команды, не правит файлы и не достраивает шаги по памяти, если справка не покрывает ваш случай.

---

## Требования

- Ссылка на сервис или инструмент, который нужно настроить (сайт сервиса, а не страница документации)
- Понимание, чего вы хотите добиться: установить, подключить, настроить, починить, перенести
- Возможность прислать доказательство: скопировать вывод команды, вставить текст ошибки или приложить скриншот
- Доступ в интернет для скила, чтобы он мог прочитать официальную справку

**Важно:** Скил намеренно ничего не запускает. Он не станет выполнять за вас установщик или проверку и откажется от такой просьбы — все изменения на вашей машине и в вашем аккаунте остаются под вашим контролем.

---

## Как использовать

1. **Начните со ссылки на сервис**
   - Скажите «помоги настроить example.com» — или, если интерфейс поддерживает слэш-команды, запустите `/setup-wizard https://example.com`
   - Без ссылки скил запросит её и будет ждать

2. **Назовите задачу**
   - Ответьте на открытый вопрос о том, чего вы хотите добиться
   - Дайте уточнения, если их спросят (ОС, версия, как планируете использовать)

3. **Подтвердите формулировку задачи**
   - Скил вернёт одну строку: `Задача: <что и в каких условиях>`
   - Пока вы её не подтвердите, ничего не происходит — это гейт, который держит маршрут честным

4. **Посмотрите карту маршрута**
   - Вы сразу видите полный список шагов и общее число N
   - Если маршрут изменится по ходу, скил объявит об этом и покажет новую карту

5. **Идите по одному шагу**
   - В каждой реплике — одно действие, ожидаемый результат и какой артефакт прислать
   - Маскируйте токены, ключи и пароли перед отправкой

6. **Прочитайте финальную сводку**
   - Достигнута ли заявленная задача, чем это подтверждено и что осталось за границей маршрута

## Примеры

### Пример 1: Установка CLI и подключение аккаунта

**Ввод:** `/setup-wizard https://example-service.com` → «Хочу поставить CLI на macOS и войти под существующим аккаунтом.»

**Действие:** Скил подтверждает формулировку, находит официальные страницы про установку и аутентификацию и строит маршрут из 4 шагов.

**Результат:**
```
[setup-wizard] 🗺️ Строю маршрут: 4 шага

Задача: установить CLI на macOS и подключить существующий аккаунт

1. Проверка предусловий
2. Установка CLI
3. Вход в аккаунт
4. Проверка подключения
```

Дальше — по шагам:
```
[setup-wizard] ▶️ Веду шаг 2/4: установка CLI

Шаг 2/4 — установка CLI
Действие: выполнить команду установки из официальной инструкции для macOS
Ожидаемый результат: команда завершается без ошибок, `svc --version` печатает версию
Пришли: полный вывод `svc --version`
```

---

### Пример 2: Справка не покрывает ваш случай

**Ввод:** «Помоги настроить example.com на Windows» — в официальной справке описаны только Linux и macOS.

**Действие:** Скил останавливается, а не собирает маршрут для Windows из блогов.

**Результат:**
```
[setup-wizard] 🛑 Официальной справки нет: установка example.com на Windows

В официальной документации есть только Linux и macOS. Маршрут по сторонним
статьям строить не буду. Варианты: использовать WSL (если инструкция для Linux
применима), спросить поддержку сервиса про Windows, переформулировать задачу.
```

---

### Пример 3: Шаг не проходит три раза подряд

**Ввод:** Шаг входа возвращает ошибку аутентификации, три попытки не помогли.

**Действие:** Скил прекращает подцикл разбора, а не крутит его бесконечно.

**Результат:**
```
[setup-wizard] 🛑 Останавливаю разбор: шаг 3, 3 попытки

Известно: CLI установлен и достучался до сервера. Исключено: неверный пароль,
устаревший локальный конфиг, помехи прокси.
Варианты:
1. Войти через браузерный флоу вместо токена
2. Откатить шаг 3 и повторить шаг 2 альтернативным способом установки
3. Обратиться в поддержку сервиса с текстом ошибки из попытки 3
```

## Триггеры

Используйте любую из этих фраз для активации скила:

| English | Русский |
|---------|---------|
| Set up this service | Настрой этот сервис |
| Help me install | Помоги установить |
| Walk me through the setup | Проведи по настройке |
| I can't get this tool configured | Не получается настроить инструмент |
| Guide me through connecting my account | Проведи по подключению аккаунта |
| `/setup-wizard <service-url>` | `/setup-wizard <ссылка-на-сервис>` |
