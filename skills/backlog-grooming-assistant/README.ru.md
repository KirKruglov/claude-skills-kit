# Backlog Grooming Assistant

Подготовка к груминг-сессии за несколько минут — флагирование проблемных задач и генерация повестки из локального CSV или Markdown-экспорта.

---

## Обзор

Backlog Grooming Assistant читает локальный экспорт бэклога (CSV или Markdown-таблица), флагирует позиции с типовыми проблемами — нет владельца, нет оценки, устаревшие задачи, заблокированные задачи без даты разблокировки, перегрузка критическими приоритетами — и формирует структурированную повестку груминг-сессии со scorecard. Не требует подключения к Jira API или внешним сервисам; работает целиком из вставленного или загруженного содержимого файла. Используйте скил при подготовке к спринт-груминг, аудите накопившегося бэклога или ревью открытых задач после спринта.

---

## Требования

- Экспорт бэклога (CSV с заголовками колонок или Markdown-таблица)
  - Минимум: колонка с ID/номером и колонка с заголовком задачи
  - Дополнительно (рекомендуется): владелец, приоритет, оценка/story points, статус, дата последнего обновления
- Сторонние инструменты или внешние сервисы не нужны

**Рекомендуется:** экспортируйте CSV прямо из Jira, Linear, Notion или любого таск-трекера; либо скопируйте Markdown-таблицу из проектного wiki.

---

## Как использовать

1. **Экспортируйте бэклог**
   - Скачайте CSV из Jira/Linear/Notion или скопируйте Markdown-таблицу из файла проекта

2. **Запустите скил**
   - Напишите: «Подготовь повестку груминга» или «Груминг-ассистент»
   - На английском: "Groom my backlog" или "Backlog grooming assistant"

3. **Вставьте или загрузите содержимое бэклога**
   - Скил автоматически определяет формат (CSV или Markdown)
   - Сопоставляет распространённые варианты названий колонок (например, «SP» → оценка, «Assignee» → владелец)

4. **Изучите груминг-отчёт**
   - Получите Markdown-документ: Scorecard, таблица «Топ-проблем» и Повестка груминга
   - Используйте повестку как структуру встречи — каждая тема содержит список задач и рекомендуемое действие

## Примеры

### Пример 1: Флагирование задач без владельца и без оценки

**Входные данные (CSV):**
```
ID,Заголовок,Владелец,Оценка,Статус,Приоритет,Обновлено
PROJ-42,Редизайн страницы входа,,,"В работе",Высокий,2026-04-20
PROJ-43,Исправить пагинацию поиска,alice,3,В работе,Средний,2026-05-10
PROJ-44,Добавить экспорт,,,Бэклог,Высокий,2026-04-01
PROJ-45,Обновить документацию API,,2,Бэклог,Низкий,2026-05-12
```

**Действие:** Скил парсит 4 задачи, применяет 7 проверок, обнаруживает: перегрузку приоритетами (50% Высоких), устаревание PROJ-44 (42 дня), отсутствие владельца у PROJ-42, PROJ-44, PROJ-45.

**Вывод:**
```markdown
# Груминг-отчёт — 2026-05-13

## Scorecard
- Всего позиций: 4
- С флагами: 3 (75%)
- Без владельца: 3
- Без оценки: 2
- Устаревших (>14 дней): 1
- Заблокированных без ETA: 0
- Перегрузка приоритетами: ДА (50% Высоких)

## Топ-проблем для груминга

| Позиция | Заголовок | Флаги | Приоритет |
|---------|-----------|-------|-----------|
| PROJ-44 | Добавить экспорт | NO_OWNER, NO_ESTIMATE, STALE | Высокий |
| PROJ-42 | Редизайн страницы входа | NO_OWNER, NO_ESTIMATE | Высокий |
| PROJ-45 | Обновить документацию API | NO_OWNER | Низкий |

## Повестка груминга

### 1. Назначить владельцев задачам без исполнителя
**Позиции:** PROJ-42, PROJ-44, PROJ-45
**Проблема:** 3 задачи без назначенного владельца
**Рекомендуемое действие:** Назначить ответственного перед стартом спринта

### 2. Оценить задачи без story points
**Позиции:** PROJ-42, PROJ-44
**Проблема:** 2 задачи без оценки
**Рекомендуемое действие:** Оценить командой во время груминга

### 3. Ревью устаревших задач
**Позиции:** PROJ-44
**Проблема:** 42 дня без активности
**Рекомендуемое действие:** Подтвердить актуальность или закрыть/архивировать

### 4. Пересмотреть приоритеты — слишком много Высоких
**Проблема:** 50% задач с высоким приоритетом (инфляция приоритетов)
**Рекомендуемое действие:** Ранжировать задачи и понизить минимум 1 до Среднего
```

### Пример 2: Бэклог в формате Markdown-таблицы

**Входные данные (Markdown-таблица):**
```
| # | Заголовок | Статус | Владелец | Приоритет |
|---|-----------|--------|----------|-----------|
| 1 | Редизайн онбординга | Заблокировано | bob | Критический |
| 2 | Баг в уведомлениях | В работе | alice | Высокий |
| 3 | Производительность дашборда | Заблокировано | | Высокий |
| 4 | Краш мобильного на iOS 17 | Бэклог | | Критический |
```

**Действие:** Скил парсит Markdown-таблицу, обнаруживает 2 заблокированные задачи без ETA, 2 задачи без владельца, инфляцию приоритетов (75% Высоких/Критических), отсутствие колонки с оценкой (проверка пропущена и указана в выводе).
