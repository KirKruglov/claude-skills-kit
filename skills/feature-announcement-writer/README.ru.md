# Feature Announcement Writer

Превратите описание фичи в готовый пакет анонса для 4 каналов — без навыков копирайтинга.

---

## Обзор

Feature Announcement Writer генерирует коммуникационный пакет из одного plain-language описания продуктовой фичи. Скил формирует четыре готовых формата: запись в changelog, email-анонс, push-уведомление и пост для социальных сетей — с учётом аудитории и типа запуска. Используйте этот скил, когда нужно подготовить коммуникацию для нескольких каналов сразу при запуске фичи, сформировать анонс бета-версии без участия маркетинга, или адаптировать техническое описание фичи в user-facing текст.

---

## Требования

- Описание фичи (plain text, вставленный прямо в чат или файл `.md` — минимум 1 абзац)
- Опционально: название продукта, название фичи, тип аудитории, тип запуска

Дополнительные инструменты не нужны. Скил работает только с тем, что вы предоставите.

---

## Как использовать

1. **Опишите фичу**
   - Напишите или вставьте 1–2 абзаца простым языком: что делает фича и кому это полезно

2. **Активируйте скил:**
   - "Напиши анонс фичи"
   - "Создай пакет анонса"
   - На английском: "Write feature announcement" или "Generate announcement for my feature"

3. **Укажите дополнительный контекст** (или оставьте дефолты)
   - Название продукта, название фичи, аудитория (users / customers / internal / developers), тип запуска (GA / beta / soft launch)
   - Дефолты: аудитория = users, тип = GA

4. **Получите пакет анонса**
   - 4 готовых блока: changelog, email, push-уведомление, пост
   - Скопируйте каждый блок в соответствующий канал

## Примеры

### Пример 1: Запуск функции экспорта

**Ввод:**
> Мы выпустили PDF-экспорт для отчётов. Теперь пользователи могут экспортировать любой отчёт в чистый, отформатированный PDF одним кликом — никаких скриншотов и ручного переформатирования. Работает для всех типов отчётов. Доступно всем пользователям с сегодняшнего дня.

**Вывод:**

📋 **Changelog:** `- PDF Экспорт: экспортируйте любой отчёт в чистый PDF одним кликом — скриншоты больше не нужны.`

📧 **Тема письма:** `Новое: экспорт отчётов в PDF — доступно сегодня`

📱 **Push:** `Экспортируйте любой отчёт в PDF одним кликом. Никаких скриншотов. Попробуйте прямо сейчас.` _(88 симв.)_

🔗 **Пост:** `Надоело делать скриншоты отчётов, чтобы ими поделиться? Мы это исправили. PDF-экспорт теперь доступен — выберите отчёт, нажмите экспорт, готово. Попробуйте и расскажите, что думаете.`

### Пример 2: Анонс бета-фичи

**Ввод:**
> Запускаем AI-резюме встреч для бета-пользователей. После каждой встречи Claude автоматически формирует структурированное резюме с ключевыми решениями, задачами и следующими шагами — прямо в рабочем пространстве. Ручное ведение заметок больше не нужно. Бета-доступ начинается на этой неделе для ранних пользователей.

**Вывод:**

📋 **Changelog:** `- [Beta] AI-резюме встреч: автоматические резюме с решениями, задачами и следующими шагами после каждой встречи.`

📧 **Тема письма:** `[Beta] AI-резюме встреч — вы в списке`

📱 **Push:** `AI-резюме встреч уже здесь. Решения, задачи и следующие шаги автоматически после каждой встречи.` _(95 симв.)_

🔗 **Пост:** `А что, если каждая встреча заканчивалась бы идеальным резюме — автоматически? На этой неделе запускаем AI-резюме встреч для ранних пользователей. Структурированный результат, никаких ручных заметок. Кто хочет попробовать?`
