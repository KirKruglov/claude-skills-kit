# Newsletter Digest Builder

Превратите папку с сохранёнными статьями и рассылками в структурированный еженедельный дайджест — по темам и релевантности вашей роли.

---

## Обзор

Newsletter Digest Builder принимает папку с сохранёнными статьями и рассылками (файлы .txt или .md) и формирует структурированный еженедельный дайджест. Скилл извлекает заголовки и содержимое из каждого файла, группирует статьи по тематическим кластерам, оценивает каждую позицию по релевантности к вашей роли (PM, маркетолог или custom), и формирует шортлист «Читать на этой неделе» из 5–7 позиций. Используйте этот скилл, когда накопилось слишком много непрочитанных статей, когда нужно быстро разобрать неделю рассылок перед планинг-сессией, или когда важно понять, что из сохранённого реально важно для текущих задач.

В отличие от инструментов для работы с одним файлом, этот скилл обрабатывает всю папку за один проход — без ручной сортировки.

---

## Что нужно

- Папка с сохранёнными статьями в формате `.txt` или `.md` — одна статья на файл
  - Поддерживаются: файлы с текстом статей, markdown-рассылки, сохранённые посты из блогов
  - Работает с файлами, содержащими только URL (дайджест будет сформирован по метаданным ссылки)
  - Минимум 1 файл; оптимально — 5–20 статей
- Ваша текущая роль или фокус, указанные в сообщении (например, «PM, фокус на AI-инструментах для B2B» или «Маркетолог, строю demand gen»)
- Дополнительные инструменты или скиллы не нужны

**Совет:** сохраняйте рассылки и статьи недели в одну папку (например, `newsletters/week-21/`). Скилл читает все файлы за один проход.

---

## Как использовать

1. **Подготовьте папку со статьями**
   - Сохраните рассылки и статьи этой недели в файлы `.txt` или `.md`
   - Загрузите файлы в чат или укажите путь к папке

2. **Запустите скилл:**
   - «Собери дайджест из рассылок» или «Сделай еженедельный дайджест»
   - На английском: "Build my newsletter digest" или "Summarize my saved articles"

3. **Укажите роль и фокус**
   - Добавьте 1–2 предложения: «Я PM, работаю над AI-инструментом для enterprise» или «Маркетолог, сейчас фокус на SEO и organic growth»
   - Скилл спросит, если вы забудете — без этого приоритизация невозможна

4. **Получите еженедельный дайджест**
   - Ответ в markdown: шортлист «Читать на этой неделе» (5–7 позиций) и полный список по темам
   - Каждая статья помечена [Must Read] / [Useful] / [Optional] по релевантности к вашей роли

## Примеры

### Пример 1: PM разбирает рассылки за неделю

**Содержимое папки (5 файлов):**
```
ai-product-lessons.md       — «Чему мы научились, запуская первую AI-фичу»
churn-analysis-guide.md     — «Как проводить cohort-анализ оттока»
design-tokens-deep-dive.md  — «Design Tokens: подробный разбор»
b2b-saas-benchmarks.txt     — «Бенчмарки B2B SaaS 2026»
remote-leadership.txt       — «Управление распределёнными командами в 2026»
```

**Роль:** «Я PM, создаю AI-продукт для аналитики в B2B SaaS, фокус на снижении time-to-insight.»

**Результат:**
```
## Еженедельный дайджест — 2026-05-21
**Роль:** PM, AI-аналитика для B2B SaaS, фокус на time-to-insight
**Статей обработано:** 5

---

### Читать на этой неделе (Топ-3)
1. **Чему мы научились, запуская первую AI-фичу** — AI/Продукт · Ключевые уроки для вашей AI-разработки
2. **Как проводить cohort-анализ оттока** — Аналитика · Прямо по теме ваших метрик
3. **Бенчмарки B2B SaaS 2026** — Рынок · Необходимый контекст для позиционирования

---

### Полный список по темам

#### AI / Продукт
- [Must Read] **Чему мы научились, запуская первую AI-фичу**

#### Аналитика
- [Must Read] **Как проводить cohort-анализ оттока**

#### Рынок
- [Must Read] **Бенчмарки B2B SaaS 2026**

#### UX / Дизайн
- [Useful] **Design Tokens: подробный разбор**

#### Лидерство
- [Optional] **Управление распределёнными командами в 2026**

---

### Можно пропустить на этой неделе
- [Optional] **Управление распределёнными командами** — тема лидерства не в приоритете при текущем продуктовом фокусе
```

```
4. **Дистрибуция через LinkedIn** — Дистрибуция · Полезно для усиления контента
5. **Brand storytelling для SaaS** — Контент-стратегия · Сильный второй приоритет

```
