# Reading List Prioritizer

Превратите кучу сохранённых статей в сфокусированный план чтения на неделю — по темам и релевантности вашей роли.

---

## Обзор

Reading List Prioritizer принимает ваш список чтения (markdown-файл с заголовками и ссылками на статьи) и возвращает структурированный план чтения на неделю. Скилл определяет темы среди сохранённых статей, оценивает каждую по релевантности к вашей роли и фокусу, и формирует шортлист «Читать на этой неделе» из 5–7 позиций. Используйте этот скилл, когда список чтения вырос до неуправляемых размеров, когда нужно расставить приоритеты под конкретный проект или фокус, или когда необходимо подготовиться к стратегической сессии.

---

## Что нужно

- Markdown-файл (.md) с вашим списком чтения
  - Поддерживаемые форматы: ссылки `[Заголовок](URL)`, голые URL, простой текст — или всё вместе
  - Минимум 3 позиции; работает со списками любого размера
- Ваша текущая роль или фокус, указанные в сообщении (например, «PM, фокус на AI-продуктах для B2B»)
- Дополнительные инструменты или скиллы не нужны

**Совет:** экспортируйте список чтения из Notion, Obsidian или любого другого приложения в формате markdown. Или вставьте список прямо в чат.

---

## Как использовать

1. **Подготовьте список чтения**
   - Экспортируйте сохранённые статьи в `.md`-файл или вставьте список в чат
   - Заголовки и/или ссылки — обычный текст тоже подойдёт

2. **Запустите скилл:**
   - «Расставь приоритеты в списке чтения» или «Что мне читать в первую очередь?»
   - На английском: "Prioritize my reading list" или "What should I read first?"

3. **Укажите роль и фокус**
   - Добавьте 1–2 предложения: «Я PM, строю AI-ассистент для записей» или «Контент-маркетолог, сейчас фокус на SEO»
   - Скилл спросит, если вы забудете — без этого приоритизация невозможна

4. **Получите план чтения**
   - Ответ в markdown: шортлист «Читать на этой неделе» (5–7 позиций) и полный список по темам
   - Каждая статья помечена [High] / [Med] / [Low] по релевантности к вашему фокусу

## Примеры

### Пример 1: Недельная подготовка PM к чтению

**Входные данные:**
```
- [Почему AI-продукты проваливаются](https://hbr.org/article-1)
- [Дизайн-системы в масштабе](https://nngroup.com/article-2)
- [Будущее труда](https://mckinsey.com/article-3)
- [Технический отчёт GPT-4](https://arxiv.org/article-4)
- [Метрики продукта, которые важны](https://lenny.substack.com/article-5)
- [UX-исследования на мобайле](https://smashingmagazine.com/article-6)
- [Теория агрегации](https://stratechery.com/article-7)
- [Управление удалёнными командами](https://hbr.org/article-8)
```

**Роль:** «Я PM, создаю AI-ассистент для B2B SaaS.»

**Результат:**
```
## План чтения — 2026-05-20
**Фокус:** PM, создаёт AI-ассистент для B2B SaaS
**Позиций:** 8

### Читать на этой неделе (Топ-6)
1. Почему AI-продукты проваливаются — AI/Стратегия · Прямо по теме: типичные провалы AI-команд
2. Технический отчёт GPT-4 — AI/Данные · Базовый контекст для принятия решений по AI
3. Метрики продукта, которые важны — Продукт · Ключевые для определения метрик успеха
4. Теория агрегации — Бизнес-стратегия · Полезна для платформенного мышления
5. Дизайн-системы в масштабе — UX/Дизайн · Релевантна для масштабирования UI
6. Управление удалёнными командами — Лидерство · Полезно для PM распределённой команды

### Полный список по темам

#### AI / Данные
- [High] Почему AI-продукты проваливаются
- [High] Технический отчёт GPT-4

#### Продукт
- [High] Метрики продукта, которые важны

#### UX / Дизайн
- [Med] Дизайн-системы в масштабе
- [Low] UX-исследования на мобайле

#### Бизнес-стратегия
- [Med] Теория агрегации
- [Med] Будущее труда

#### Лидерство
- [Med] Управление удалёнными командами

### Можно пропустить на этой неделе
- [Low] UX-исследования на мобайле — мобильный UX не релевантен для B2B web-ассистента
```

### Пример 2: Контент-маркетолог, список с фильтрацией по фокусу

**Входные данные:**
```
[Content-led Growth](https://contentledgrowth.com/post-1)
[SEO в эпоху AI](https://seoblog.com/post-2)
[B2B-копирайтинг: фреймворки](https://copywriting.substack.com/post-3)
[Kubernetes Best Practices](https://devops.io/post-4)
[Алгоритм LinkedIn 2026](https://socialmedia.tips/post-5)
[Написание текстов для разработчиков](https://techwriting.dev/post-6)
```

**Роль:** «Контент-маркетолог в B2B SaaS, фокус на SEO и top-of-funnel.»

**Результат:**
```
## План чтения — 2026-05-20
**Фокус:** Контент-маркетолог в B2B SaaS, SEO и top-of-funnel

### Читать на этой неделе (Топ-4)
1. SEO в эпоху AI — SEO · Прямо по теме
2. Content-led Growth — Контент-стратегия · Базовая тема для top-of-funnel
3. B2B-копирайтинг: фреймворки — Копирайтинг · Высокая ценность для B2B-контента
4. Алгоритм LinkedIn 2026 — Дистрибуция · Полезно для распространения top-of-funnel

### Можно пропустить на этой неделе
- [Low] Kubernetes Best Practices — инженерная тема, вне вашего фокуса
```
