# CSV Data Analyzer

Анализируй любой CSV-файл через диалоговый сценарий — без кода, без Python, без внешних плагинов. Claude читает файл напрямую, профилирует структуру данных и помогает найти нужные инсайты через один уточняющий вопрос.

Скил создан для нетехнических пользователей, которые регулярно работают с экспортированными данными: отчёты по продажам, списки задач, выгрузки из CRM, результаты опросов, файлы расходов.

---

## Требования

- CSV-файл, доступный в рабочем пространстве Cowork (загружен или находится в выбранной папке)
- Дополнительная настройка, API-ключи и внешние инструменты не нужны

---

## Как использовать

1. Загрузи CSV-файл в Cowork (или убедись, что он находится в выбранной папке)
2. Активируй скил одной из фраз ниже
3. Claude профилирует датасет и задаёт один вопрос: что ты хочешь понять?
4. Ответь в свободной форме — Claude выполнит анализ и выдаст пронумерованные инсайты
5. Изучи результаты и при необходимости продолжи исследование в другом направлении

---

## Примеры

**Пример 1: Экспорт продаж**

> «Проанализируй CSV» + загрузка `sales-q1.csv`

Claude читает файл, сообщает: 847 строк, 6 колонок (дата, регион, продукт, единицы, выручка, менеджер). Спрашивает: «Что ты хочешь понять — сводная статистика, тренды во времени, топ/аутсайдеры или что-то ещё?» Пользователь отвечает: «Какой продукт принёс больше всего выручки?» → Claude возвращает таблицу продуктов по выручке с понятным объяснением.

**Пример 2: Список задач**

> «Что в этом CSV» + указание на `sprint-tasks.csv`

Claude профилирует файл: 63 строки, колонки — статус, исполнитель, приоритет, оценка. Пользователь: «Покажи, как задачи распределяются по статусу». Claude возвращает сгруппированную таблицу и отмечает, что 40% задач всё ещё в статусе «В работе», хотя спринт заканчивается на этой неделе.

## Что скил умеет и не умеет

**Умеет:**
- Читать CSV-файлы напрямую из рабочего пространства Cowork
- Профилировать структуру: количество строк, типы колонок, пустые ячейки, пропущенные данные
- Выполнять анализ на естественном языке: сводка, тренды, рейтинги, сравнение групп
- Формулировать инсайты понятным бизнес-языком без технических терминов
- Обрабатывать большие файлы через выборку (>500 строк)

**Не умеет:**
- Генерировать графики и визуализации (для этого вставь таблицу в Excel или Google Sheets)
- Выполнять Python или другой код
- Подключаться к внешним базам данных или API
- Изменять или перезаписывать исходный файл
