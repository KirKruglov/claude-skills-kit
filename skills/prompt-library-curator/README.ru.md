# Prompt Library Curator

Структурируйте и тегируйте свою коллекцию промптов в организованный markdown-каталог — без ручной сортировки.

## Обзор

У вас накопились промпты в заметках, файлах или истории чатов — но они разбросаны и их сложно найти в нужный момент. **Prompt Library Curator** преобразует вашу сырую коллекцию промптов в чистый файл `prompt-library.md` с категориями, тегами, индексной таблицей и определением дублей. В отличие от скилов для создания промптов, этот скил курирует то, что у вас уже есть.

## Требования

- Ваши промпты в виде вставленного текста или файла `.md` / `.txt`
- Минимум 1 промпт (рекомендуется 5–100 для лучшего результата)

## Как использовать

1. Активируйте скил одной из фраз-триггеров ниже
2. Вставьте промпты прямо в чат — или укажите путь к файлу `.md`/`.txt`
3. Получите структурированный каталог `prompt-library.md` с категориями, тегами и индексной таблицей

Скил сохраняет оригинальный текст промпта без изменений. Метаданные добавляются вокруг промпта, а не внутри него.

## Примеры

**Пример 1 — Вставленный список:**

> *«организуй мои промпты»*
> [вставьте 20 промптов, разделённых пустыми строками]

→ Возвращает `prompt-library.md` с индексной таблицей, 4 категориями, 2 отмеченными дублями.

**Пример 2 — На основе файла:**

> *«структурируй промпты — они у меня в файле prompts.md»*

→ Читает `prompts.md`, назначает теги и уровень сложности каждому промпту, выводит структурированный каталог.

## Триггеры

| Русский | English |
|---------|---------|
| `организуй мои промпты` | `organize my prompts` |
| `библиотека промптов` | `prompt library` |
| `разбери мою коллекцию промптов` | `tag my prompts` |
| `структурируй промпты` | `structure my prompt collection` |
