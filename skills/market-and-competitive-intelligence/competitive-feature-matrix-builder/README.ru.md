# Competitive Feature Matrix Builder

Превращает папку с конкурентными заметками в структурированную таблицу сравнения фич и gap-анализ — без интернета, без API, полностью офлайн.

---

## Обзор

Competitive Feature Matrix Builder читает локальные заметки о конкурентах (md или txt файлы) и формирует готовую для шаринга markdown-матрицу с перечнем фич по каждому конкуренту и приоритизированным gap-анализом. Работает только с вашими файлами — никакого веб-поиска или внешних API не нужно. Используйте этот скил, когда нужно собрать разрозненные конкурентные заметки перед роадмап-сессией, провести квартальный конкурентный обзор или определить, какие фичи приоритизировать, исходя из покрытия рынка.

---

## Требования

- Папка с конкурентными заметками в формате `.md` или `.txt` (рекомендуется один файл на конкурента)
- Опционально: файл `your-product.md` или `own-product.md` в той же папке для сравнения с вашим продуктом и gap-анализа
- Никаких дополнительных инструментов, API или интернет-доступа не требуется

**Рекомендация:** 2–6 файлов по конкурентам, каждый — не менее 5–10 заметок на уровне фич. Чем структурированнее заметки (маркированные списки, заголовки), тем точнее извлечение.

---

## Как использовать

1. **Подготовьте конкурентные заметки**
   - Сохраните исследование по каждому конкуренту в отдельный `.md` или `.txt` файл (например, `salesforce.md`, `hubspot.md`)
   - Опционально добавьте `your-product.md` со списком фич вашего продукта для gap-сравнения

2. **Запустите скил фразой:**
   - "Составь feature matrix по моим заметкам"
   - "Матрица фич конкурентов"
   - По-английски: "Build a competitive feature matrix" или "Competitive feature matrix"

3. **Укажите путь к папке**
   - Укажите путь к папке с заметками (или откройте её в Cowork)
   - Скил просканирует все md/txt файлы, извлечёт фичи и нормализует их

4. **Изучите результат**
   - Получите таблицу Feature Matrix, раздел Gap Analysis и Рекомендации
   - Скопируйте markdown в роадмап-документ, презентацию или поделитесь с командой

## Примеры

### Пример 1: Анализ трёх конкурентов SaaS

**Входные данные:**
```
Папка: /competitive-research/
Файлы: hubspot.md, salesforce.md, pipedrive.md, your-product.md
```

**Действие:** Скил сканирует 4 файла, извлекает названия конкурентов из заголовков, нормализует 12 фич по всем файлам.

**Результат (фрагмент):**
```markdown
Обработано 4 файла: HubSpot, Salesforce, Pipedrive, Ваш продукт. Матрица охватывает 12 фич.

## Feature Matrix

| Фича | HubSpot | Salesforce | Pipedrive | Ваш продукт |
|------|:---:|:---:|:---:|:---:|
| Email-последовательности | ✓ | ✓ | ✓ | ✗ |
| Мобильное приложение | ✓ | ✓ | ✓ | ✓ |
| AI-скоринг лидов | ✓ | ✓ | ✗ | ✗ |
| Автоматизация пайплайна | ✓ | ✓ | ✓ | ✓ |

## Gap Analysis

| Фича | Конкуренты с фичей | Приоритет |
|------|-------------------|-----------|
| Email-последовательности | HubSpot, Salesforce, Pipedrive | Высокий |
| AI-скоринг лидов | HubSpot, Salesforce | Средний |
```

---

### Пример 2: Сравнение двух конкурентов без файла собственного продукта

**Входные данные:**
```
Папка: /research/q2-competitive/
Файлы: notion-notes.txt, coda-notes.txt
```

**Действие:** Скил сканирует 2 файла, извлекает списки фич из маркированных пунктов и текста, строит матрицу из 2 столбцов.

**Результат (фрагмент):**
```markdown
Обработано 2 файла: Notion, Coda. Матрица охватывает 8 фич.
Примечание: добавьте файл `your-product.md` для сравнения с вашим продуктом и gap-анализа.

## Feature Matrix

| Фича | Notion | Coda |
|------|:---:|:---:|
| Представления базы данных | ✓ | ✓ |
| Автоматизация / Воркфлоу | ? | ✓ |
| AI-помощник для текстов | ✓ | ✓ |
| Язык формул | ✗ | ✓ |

*Легенда: ✓ = подтверждено наличие, ✗ = подтверждено отсутствие, ? = не упоминается в заметках*
```
