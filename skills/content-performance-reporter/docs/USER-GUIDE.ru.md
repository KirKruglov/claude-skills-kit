# Руководство пользователя — Content Performance Reporter

## Что делает этот скил

Content Performance Reporter читает CSV-экспорты недельной аналитики и превращает их в структурированный нарратив: какой контент сработал лучше всего, какой провалился, какой паттерн прослеживается, и что приоритизировать на следующей неделе.

Ты получаешь редакционный отчёт — не таблицу, не дашборд. Claude сортирует, агрегирует и интерпретирует данные, чтобы ты мог сосредоточиться на решениях.

---

## Пошаговая инструкция

### 1. Экспортируй аналитику в CSV

Каждая платформа имеет свой способ экспорта:

- **YouTube:** YouTube Studio → Аналитика → Иконка экспорта (справа вверху) → CSV
- **Google Analytics:** Отчёты → выбери период → Скачать → CSV
- **LinkedIn:** LinkedIn Analytics → Экспорт (справа вверху) → Экспорт публикаций
- **TikTok:** TikTok Business Center → Аналитика → Скачать
- **Twitter/X:** Analytics.twitter.com → Вкладка «Твиты» → Экспорт данных

### 2. Загрузи файл в Cowork

Перетащи CSV-файл в чат Cowork или убедись, что он уже находится в выбранной рабочей папке.

### 3. Активируй скил

Напиши одну из фраз:
- «Отчёт по контенту»
- «Что сработало на этой неделе»
- «Скомпилируй аналитику»

Или по-английски:
- "content performance report"
- "what worked this week"
- "compile my analytics"

### 4. Изучи отчёт

Claude вернёт структурированный отчёт:

- **Таблица метрик** — суммарный охват/просмотры, средний ER, сравнение с прошлой неделей (если есть данные)
- **Топ-3 поста** — лучший контент с ключевыми метриками
- **Аутсайдеры-3** — слабейший контент
- **Что сработало** — конкретные выводы с числами
- **Что не сработало** — конкретные выводы с числами
- **Паттерн недели** — общая тема среди топ-перформеров
- **Рекомендация на следующую неделю** — 1–2 конкретных действия

## Советы

**Запускай несколько платформ за один раз.** Загрузи вместе файлы, YouTube и GA4 — Claude создаст отдельный раздел для каждой платформы и общий Summary.

**Сравни две недели.** Если платформа экспортирует данные за два периода в одном файле (колонки «эта неделя» и «прошлая неделя»), Claude посчитает дельту автоматически. Если у тебя два отдельных файла, загрузи оба и укажи, какой текущий: «файл A — текущая неделя, файл B — прошлая».

**Нет колонки с названием контента? Не проблема.** Если в CSV нет столбца с названием поста или URL (бывает в сырых GA4-экспортах), Claude использует номера строк в качестве идентификаторов и фиксирует это в Notes.

**Слишком много данных?** При файлах более 1000 строк Claude анализирует все строки для агрегированных метрик, но ограничивает топ-3/аутсайдеров-3 первыми 100 строками по основной метрике (отражается в отчёте).

## Часто задаваемые вопросы

**В: У моего CSV необычный формат — сработает ли скил?**
Claude читает большинство стандартных CSV-экспортов. Если в файле нет числовых колонок с метриками, он будет пропущен с примечанием. Если платформа не распознана — Claude переходит в generic-режим (первые числовые колонки как метрики).

**В: Можно получить график?**
В этом режиме графики не генерируются. Вставь таблицу метрик в Google Sheets или Excel для визуализации.

**В: Нет данных за прошлую неделю — что произойдёт?**
Claude строит отчёт только по текущей неделе и не показывает столбец дельты. Никаких придуманных сравнений.

**В: Можно сохранить отчёт в файл?**
Да — просто попроси: «сохрани отчёт в файл». Claude запишет его как markdown-документ в рабочую папку.

**В: Скил изменит мои исходные CSV?**
Нет. Скил читает файлы только на чтение — исходные данные никогда не перезаписываются.
