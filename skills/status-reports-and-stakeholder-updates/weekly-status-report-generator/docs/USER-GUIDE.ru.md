# Руководство пользователя — Weekly Status Report Generator

Это руководство описывает реалистичные сценарии использования скилла и советы для получения лучших результатов.

---

## Быстрый старт

1. Открой новую сессию с Claude.
2. Напиши: **«Напиши мой еженедельный статус-отчёт»**
3. Вставь сырые заметки недели — любой формат подойдёт.
4. Получи Статус-отчёт для менеджера и Краткий апдейт для skip-level — готовы к отправке.

---

## Сценарии

### Сценарий 1: Пятничный отчёт меньше чем за 2 минуты

**Ситуация:** Пятница, вечер. У тебя разрозненные заметки из Slack, таск-трекера и нескольких встреч. Менеджер ждёт обновление до конца дня.

**Что делать:**
1. Открой сессию с Claude.
2. Напиши: «Напиши мой еженедельный статус-отчёт»
3. Вставь всё, что есть — может быть беспорядок:
   ```
   выкатил переработку онбординг-флоу (наконец-то!), сделал ревью PR Алекса, провёл планинг Q3 — скоуп пока размыт, жду брендовые ассеты от дизайна, следующая неделя: финализировать роадмап Q3, встреча с продажами
   ```
4. Скилл автоматически выделит Выполнено, В работе, Блокеры и На следующей неделе.
5. Скопируй блок Статус-отчёта и вставь в командный чат или письмо.

**Ожидаемый результат:** Чистый статус из 4 разделов, отправлен меньше чем за 2 минуты, без форматирования вручную.

---

### Сценарий 2: Апдейт для skip-level на ежемесячной встрече

**Ситуация:** На следующей неделе ежемесячная встреча со skip-level. Хочешь подготовить чёткое резюме из 3 пунктов по итогам месяца.

**Что делать:**
1. Собери ключевые достижения, сложности и фокус на следующий месяц из своих заметок.
2. Напиши: «Напиши мой еженедельный статус-отчёт» (формат краткого апдейта подходит и для месячного резюме).
3. Вставь краткий итог:
   ```
   Запустил A/B-тест на странице цен — конверсия выросла на 12%. Провёл продуктовый планинг. В работе: редизайн admin-дашборда. Главная сложность: размытые требования от продакта тормозили работу. Фокус следующего месяца: закрыть редизайн дашборда и запустить аналитический ревамп.
   ```
4. Скопируй только блок **Краткий апдейт для skip-level**.

**Ожидаемый результат:** Сфокусированное резюме из 3 пунктов — Топ-результат, Главная сложность, Фокус — готово к использованию на встрече или отправке как пре-рид.

---

### Сценарий 3: Делегируй подготовку отчёта Claude в напряжённую неделю

**Ситуация:** Напряжённая неделя, командировка. У тебя 30 секунд, а не 10 минут.

**Что делать:**
1. Быстро набросай что угодно — даже транскрипцию голосовой заметки или сырые Slack-сообщения:
   ```
   встреча с партнёрами в Берлине — хороший прогресс по API-спецификациям, ревью черновика договора, ничего не выкатил из-за командировки, следующая неделя — вернусь в офис, пушну партнёрский API-milestone
   ```
2. Активируй скилл. Даже скудные заметки дают полноценный отчёт — скилл предупредит, если заметки слишком краткие.
3. Отправляй Статус-отчёт как есть; используй Краткий апдейт при необходимости.

**Ожидаемый результат:** Полноценный статус из 30-секундной заметки. Скилл обеспечивает структуру — ты обеспечиваешь содержание.

---

## Советы

- **Не форматируй заметки заранее.** Чем беспорядочнее — тем лучше. Скилл одинаково хорошо разбирает списки, абзацы, нумерованные пункты и скопированные Slack-сообщения.
- **Включай метрики, если они есть.** Любое число в заметках (проценты, счётчики, даты) сохраняется дословно в отчёте — не округляй и не сокращай.
- **Только для skip-level:** можно активировать скилл ради 3 пунктов — просто проигнорируй блок Статус-отчёта для менеджера, если нужен только краткий апдейт.
- **Регулярное использование:** запускай скилл каждую пятницу с consistent заметками — получишь архив структурированных недельных обновлений без дополнительных усилий.
